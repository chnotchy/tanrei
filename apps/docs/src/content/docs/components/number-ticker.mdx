## Guidelines

### When to use

Use a number ticker for a number that changes while a person looks at it, where the change itself is worth seeing: a count that goes up as orders arrive, a price that moves, a score, the figures of a dashboard that rise to their values when the page opens. The motion shows that the number changed, which way, and roughly by how much.

A number that changes rarely, or that nobody watches change, is plain text. A level in a known range — storage used of a quota — is a [meter](/components/meter/). Times and dates are not numbers: write them with the platform's date and time formatting.

### How the number is written

The ticker has no words and no number rules of its own. The platform's number formatter writes it in the reader's language: the group and decimal separators, the currency symbol, the percent sign, the short form of a large number (1.2K, 1.2万), and the digits themselves (١٢٣٤ in Arabic as Egypt writes it). Choose a style (decimal, percent, currency or unit), a currency code or a unit, compact notation, a fixed number of fraction digits and when to write a sign; the ticker takes the language of where it stands unless you give one.

It has no font, size or color either: it is drawn in the text style of where you place it, in figures of equal width so that the number does not shift as its digits change. It can be the large figure of a dashboard card or a count inside a sentence.

### Choosing an animation

| Animation | Use for |
| --- | --- |
| Slide | Most numbers. Each changed digit's column rolls to its new digit. The default system's choice. |
| Blur | A quieter change: the old digit blurs out as the new one comes into focus. |
| Blur slide | The same, with the digits moving a short way in the direction of the change. |
| Flip | A split-flap board: departures, a countdown, a product whose look is mechanical. |
| None | A number that must change at once. |

Keep one animation across your product: set it once for the design system (`comp.number-ticker.animation`) rather than on each ticker.

### Choosing a trend

By default every changed digit moves the way the whole number moved: up when it grew, down when it shrank, so that 19 to 20 moves both digits up. That reads as one change of one number. Choose `digit` when each place means something by itself — each digit then moves by its own change, so the ones go down from 9 to 0. `up` and `down` force one way, for a number that only ever counts one way.

### Do

- Place it in text, or give its container the text style you want it in. It takes everything from there.
- Give a label when nothing visible beside the number says what it is: "Revenue", "Orders".
- Leave live off for figures that change on their own. Turn it on only for a number the person is waiting for or changing.
- Use the start value on a dashboard so its figures rise once, the first time they are seen.

### Don't

- Don't color a rise green or a fall red through the ticker: it has no such colors. If a change means something, say it beside the number — a tag, a word, an arrow with a label.
- Don't update a number many times a second. Each change takes the motion's duration; a stream of changes reads as noise. Update it at the pace a person can follow.
- Don't use it for time. A clock's digits roll over at 59, not at 9.

## Accessibility

<ComponentAccessibility name="number-ticker" />

### What the component handles

- Assistive technology reads one text: the label, then the number as the formatter writes it. The drawn digits are hidden, so the number is never read digit by digit or as the digits passing through their windows.
- By default nothing is announced: most figures are not the point of the moment. With live set to polite, the number is announced politely once each change has settled, never a value it passes through and never one a later change replaced.
- When reduced motion is requested, the new number is there at once, the old one fading out briefly.
- It takes the language and the direction of where it stands, and writes the number again at once when either changes.
- An unknown animation, trend, style, notation, sign display or live value, a duration that is not positive, a currency or unit the formatter does not know and a value that is not a number are reported in debug builds.

### What you need to do

- If your product updates a number by itself again and again next to other content, give people a way to pause the updates or to choose how often they come (WCAG 2.2.2 Pause, Stop, Hide).
- Say what a change means in words where it matters. The motion shows that it changed; it does not say whether that is good or bad.
