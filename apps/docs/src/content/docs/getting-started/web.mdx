`@tanrei/web` contains two things: a stylesheet of design tokens as CSS custom properties, and standards-based custom elements built with Lit. It has no framework requirement.

<PreReleaseNotice registry="npm" pkg="@tanrei/web" />

## Install

### From source

You need Git, Node 22.12 or later and pnpm 12 (`corepack enable` gives you the version the repository pins). Build the package in a clone of the repository, pack it, and install the packed file in your project:

```sh
git clone https://github.com/chnotchy/tanrei.git
cd tanrei
pnpm install
pnpm --filter @tanrei/web build
pnpm --filter @tanrei/web pack --pack-destination ../tanrei-packages
```

```sh
# in your project: the path to the folder the packages were written to
npm install path/to/tanrei-packages/tanrei-web-*.tgz
```

The packed file holds what a release will publish, so everything below works the same way. To take a newer state of the source, pull, build and pack again, then install the new file.

### After the first release

```sh
npm install @tanrei/web
```

## Use

<Steps>

1. Load the tokens once, as early as possible. They are wrapped in a cascade layer (`tanrei.tokens`), so your own styles always win.

   ```js
   import '@tanrei/web/tokens.css';
   ```

2. Register the components of your design system, or only the elements you use.

   ```js
   import '@tanrei/web';
   // on a preset, its entry instead: m3-like, m3-expressive-like or cupertino
   import '@tanrei/web/m3-like';
   // or, one element at a time:
   import '@tanrei/web/components/button';
   ```

   `@tanrei/web` registers the components the default system ships and no other, so a product on it cannot reach one its system does not have. A preset's entry, `@tanrei/web/<id>`, registers what that preset ships, and `@tanrei/web/all` every component of the package. A component that only a preset ships, such as the [segmented button](/components/segmented-button/), can still be taken on purpose: include it in your system's layer and import its own module.

   The `@tanrei/web/…` specifiers are package exports: a bundler (Vite, webpack, esbuild) resolves them. Without one, a browser cannot resolve a bare specifier in `<link>` or `<script src>`, so serve the package's `dist/` and point at the files — the stylesheets as they are, and `tanrei.bundle.js`, which carries Lit and every element:

   ```html
   <link rel="stylesheet" href="/node_modules/@tanrei/web/dist/tokens.css" />
   <script type="module" src="/node_modules/@tanrei/web/dist/tanrei.bundle.js"></script>
   ```

3. Use the elements like any other HTML.

   ```html
   <tanrei-button variant="filled">Deploy</tanrei-button>
   <tanrei-button variant="outlined" size="small" disabled>Cancel</tanrei-button>
   ```

4. Give your product's words. A component has none of its own: the text of a requirement tag, the name of a close button and the like are your product's. To start with plain English for every one of them, import the English word pack once:

   ```js
   import '@tanrei/web/words/en';
   ```

   Change any of them, or give the words of another language, with `setWords()` after it. A word you give wins over the pack, and a word on an element wins over both.

   ```js
   import { setWords } from '@tanrei/web';

   setWords({ requiredText: 'Mandatory' });
   setWords({ requiredText: '必須', optionalText: '任意', closeLabel: '閉じる' }, { lang: 'ja' });
   ```

   Without the pack and without your words, a component still works, and tells you in the console which word it lacks. See [Words](/foundations/words/).

</Steps>

## The elements' manifest

Editors and coding agents read the package's elements from its [custom elements manifest](https://github.com/webcomponents/custom-elements-manifest), `@tanrei/web/custom-elements.json`: every element with its attributes, properties, events, slots and parts, and nothing a product cannot reach. `@tanrei/web/custom-elements/<id>.json` holds only the elements system `<id>` ships, so a tool that works in one system offers nothing else.

## Theme and contrast

Token values use `light-dark()`, so they follow the `color-scheme` of the element they are used on. Out of the box that means the operating system setting, and `prefers-contrast: more` switches to the high-contrast scheme.

To take control, set attributes:

```html
<!-- Force a theme for the page or for any subtree -->
<html data-tanrei-theme="dark">

<!-- Force a contrast level for the page: "medium" or "high" -->
<html data-tanrei-contrast="high">
```

<Callout>
  Both attributes work on `<html>` or on any subtree. The generated stylesheet declares the whole token set on `:root, [data-tanrei-contrast]`, so a `data-tanrei-contrast` on a nested element re-resolves the component tokens inside it against that contrast level, not only the system colors.
</Callout>

## Tokens in your own CSS

Every token is a custom property named after its path: `tanrei.sys.color.primary` becomes `--tanrei-sys-color-primary`.

```css
.panel {
  background: var(--tanrei-sys-color-surface-container-low);
  border-radius: var(--tanrei-sys-shape-corner-medium);
  box-shadow: var(--tanrei-sys-elevation-level1);
  font: var(--tanrei-sys-typescale-body-font);
}
```

## Text styles

Text styles are named by level (`heading-2` is an `h2`, `body` a `p`, `label` the text on a control), and each one is a set of custom properties: `--tanrei-sys-typescale-<role>-font` as a shorthand, plus `-font-family`, `-font-size`, `-font-weight`, `-line-height`, `-letter-spacing` and `-font-weight-emphasized`. Two optional stylesheets put them on elements for you:

```js
import '@tanrei/web/text.css';   // .tanrei-text-<role>, .tanrei-text-emphasized
import '@tanrei/web/prose.css';  // h1–h6, p, small, code, pre inside .tanrei-prose
```

```html
<h2 class="tanrei-text-heading-2">Section</h2>
<p class="tanrei-text-body">Running text with <strong class="tanrei-text-emphasized">stress</strong>.</p>
<article class="tanrei-prose"><!-- rendered Markdown --></article>
```

`.tanrei-text-emphasized` draws the role it sits in at its weight plus the family's emphasis step; it is a weight, not another role. The sixteen roles and the element mapping are on [Typography](/foundations/typography/).

## Fonts

The typescale asks for Inter, Noto Sans JP, Noto Sans and Roboto Mono (`--tanrei-ref-typeface-{brand,plain,mono}` in `tokens.css`; `tanrei build` prints the list for any system), icons for Material Symbols Rounded, and everything falls back to system fonts. Tanrei does not bundle font files; load them yourself under exactly those family names — from Google Fonts, or from the `@fontsource-variable/*` packages (which register `Inter Variable` and so on: declare your own `@font-face` with the plain name pointing at their files, as this site does).

## Icons

```js
import '@tanrei/web/icons.css';
```

```html
<tanrei-button><span slot="icon" class="tanrei-icon" aria-hidden="true">add</span>Add</tanrei-button>
```

`.tanrei-icon` draws a [Material Symbols](https://fonts.google.com/icons) name with the system's icon weight and takes its size from where it sits. You never choose outlined or filled: see [Icons](/foundations/icons/).

The whole Material Symbols Rounded file holds every glyph at every weight, fill, grade and optical size: 5.4 MB, which a page on a slow line can wait half a minute for. Load only the glyphs your product draws. `tanrei build` prints the names Tanrei's components may draw themselves (a chevron, a check, the cross of a close button…) and the axis values your system draws icons at; add your own names to that list. From Google Fonts, pass the names, sorted, as `icon_names=` and the axes as ranges in `family=` (`Material+Symbols+Rounded:opsz,wght,FILL,GRAD@20..48,300..500,0..1,0` for the default system). Serving the file yourself, cut it down with a subsetter that keeps the font's ligature features (`rlig`, `rclt`) and both fills; this site draws its icons from such a file. Either way, register the icon face with `font-display: block`: until the file is there an icon is invisible, never its name in letters.

## Browser support

The tokens rely on `light-dark()` and cascade layers, which are available in current versions of Chrome, Edge, Firefox and Safari.
