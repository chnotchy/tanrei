Las muestras se componen con las propiedades personalizadas de CSS generadas, así que lo que ves es lo que distribuye `@tanrei/web`. Cada rol expone sus partes como propiedades separadas: `-font-family`, `-font-size`, `-line-height`, `-font-weight`, `-letter-spacing` y `-font-weight-emphasized`, además de una forma abreviada `-font`. Para las pautas de uso (qué rol es un `h2` o un `p`, y por qué el énfasis es un peso y no un rol), lee [Tipografía](/es/foundations/typography/).
