## Suavizado de esquinas

`tanrei.sys.shape.corner-smoothing` es una cantidad de 0 a 1 con el significado de Figma: 0 es un cuarto de círculo, 0.6 es lo que Figma llama la esquina de iOS y 1 es la más suavizada. El radio no cambia con ella. La construcción de Figma es lo que significa la cantidad; Compose y Flutter la dibujan, la web dibuja la superelipse más cercana, y SwiftUI y React Native en iOS, la curva del sistema operativo (las distancias están en [Forma](/es/foundations/shape/#suavizado-de-esquinas)).
