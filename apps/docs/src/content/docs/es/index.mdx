## Hecho para mantenerse sincronizado

<CardGrid>
  <Card title="Dos fuentes de verdad" icon="description">
    Los tokens de diseño y las especificaciones de los componentes son los únicos contratos escritos a mano. El código de las plataformas, esta documentación y la matriz de estado se derivan de ellos, y la CI falla cuando se desvían.
  </Card>
  <Card title="Paridad, no uniformidad" icon="extension">
    Cada plataforma recibe los mismos tokens, los mismos estados y la misma semántica de accesibilidad, pero conserva la forma de su propia API: `enabled` en Compose, un `onPressed` nulo en Flutter, `.disabled(_:)` en SwiftUI.
  </Card>
  <Card title="Una estructura probada" icon="menu_book">
    Tokens de referencia, de sistema y de componente; roles de color; una escala tipográfica; paletas tonales generadas por tema y por nivel de contraste. Su aspecto es contenido, casi monocromo.
  </Card>
  <Card title="Accesible por construcción" icon="verified">
    Los pares de contraste se comprueban para cada tema y cada nivel de contraste durante la compilación. El tamaño visual nunca decide el área de pulsación, y el anillo de foco forma parte de toda especificación interactiva.
  </Card>
</CardGrid>
