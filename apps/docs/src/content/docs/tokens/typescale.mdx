Specimens are set with the generated CSS custom properties, so what you see is what `@tanrei/web` ships. Each role exposes its parts as separate properties: `-font-family`, `-font-size`, `-line-height`, `-font-weight`, `-letter-spacing` and `-font-weight-emphasized`, plus a `-font` shorthand. For guidance — which role an `h2` or a `p` is, and why emphasis is a weight rather than a role — read [Typography](/foundations/typography/).
