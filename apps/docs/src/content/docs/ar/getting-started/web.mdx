تحتوي الحزمة `@tanrei/web` على شيئين: ورقة أنماط تضم رموز التصميم (tokens) في صورة خصائص CSS مخصصة، وعناصر مخصصة قياسية مبنية بمكتبة Lit. ولا تشترط أي إطار عمل.

<PreReleaseNotice registry="npm" pkg="@tanrei/web" />

## التثبيت

### من الشيفرة المصدرية

تحتاج إلى Git، و Node 22.12 أو أحدث، و pnpm 12 (الأمر `corepack enable` يعطيك الإصدار الذي يثبّته المستودع). ابنِ الحزمة في نسخة مستنسخة من المستودع، ثم احزمها، وثبِّت الملف المحزوم في مشروعك:

```sh
git clone https://github.com/chnotchy/tanrei.git
cd tanrei
pnpm install
pnpm --filter @tanrei/web build
pnpm --filter @tanrei/web pack --pack-destination ../tanrei-packages
```

```sh
# في مشروعك: المسار إلى المجلد الذي كُتبت فيه الحزم
npm install path/to/tanrei-packages/tanrei-web-*.tgz
```

يحمل الملف المحزوم ما سينشره الإصدار، فيعمل كل ما يلي بالطريقة نفسها. ولتأخذ حالة أحدث من الشيفرة المصدرية، اسحب التغييرات (pull) وابنِ واحزم من جديد، ثم ثبِّت الملف الجديد.

### بعد الإصدار الأول

```sh
npm install @tanrei/web
```

## الاستخدام

<Steps>

1. حمِّل أوراق الأنماط مرة واحدة، وفي أبكر وقت ممكن. كلها موضوعة داخل طبقات تتالٍ (`tanrei.*`)، فتكون الغلبة دائمًا لأنماطك أنت.

   ```js
   import '@tanrei/web/tanrei.css';
   ```

   الملف `tanrei.css` يضم كل شيء في ملف واحد: أساس الصفحة، والرموز، وأوراق أنماط الأجزاء التي تُرسم من دون عنصر (أنماط النص، والجدول، والأكورديون، وغيرها). ولتحمّل ما تستخدمه وحده، خذ الرموز، والأساس إن أردته، وكل ورقة من تلك الأوراق حين تحتاج إليها:

   ```js
   import '@tanrei/web/tokens.css';
   import '@tanrei/web/base.css'; // الصفحة بلون سطح النظام ولون نصه وخط المتن، ومن دون هامش على body
   ```

   يعطي الأساس الصفحة نفسها لون السطح، ويعطي نصك أنت اللون on-surface وخط المتن، ويزيل الهامش الذي يضعه المتصفح على body. ومن دونه تبقى الصفحة على إعدادات المتصفح الافتراضية.

2. سجِّل مكوّنات نظام التصميم الخاص بك، أو العناصر التي تستخدمها فقط.

   ```js
   import '@tanrei/web';
   // في إعداد جاهز، مدخله بدلًا من ذلك: m3-like أو m3-expressive-like أو cupertino
   import '@tanrei/web/m3-like';
   // أو عنصرًا واحدًا في كل مرة:
   import '@tanrei/web/components/button';
   ```

   لا يسجّل `@tanrei/web` إلا المكوّنات التي يتضمنها النظام الافتراضي، فلا يصل المنتج المبني عليه إلى مكوّن لا يملكه نظامه. ويسجّل مدخل الإعداد الجاهز، `@tanrei/web/<id>`، ما يتضمنه ذلك الإعداد، ويسجّل `@tanrei/web/all` كل مكوّنات الحزمة. والمكوّن الذي لا يتضمنه إلا إعداد جاهز، مثل [الزر المقسَّم](/ar/components/segmented-button/)، يمكن أخذه مع ذلك عن قصد: ضمّنه في طبقة نظامك واستورد وحدته الخاصة.

   المحدِّدات من الصيغة `@tanrei/web/…` هي صادرات الحزمة (package exports)، ويحلّها المُحزِّم (Vite أو webpack أو esbuild). ومن دون مُحزِّم لا يستطيع المتصفح حلّ محدِّد مجرّد في `<link>` أو `<script src>`؛ لذلك قدِّم مجلد `dist/` من الحزمة وأشِر إلى الملفات مباشرة: أوراق الأنماط كما هي، والملف `tanrei.bundle.js` الذي يحمل Lit وجميع العناصر:

   ```html
   <link rel="stylesheet" href="/node_modules/@tanrei/web/dist/tanrei.css" />
   <script type="module" src="/node_modules/@tanrei/web/dist/tanrei.bundle.js"></script>
   ```

3. استخدم العناصر كأي عنصر HTML آخر.

   ```html
   <tanrei-button variant="filled">نشر</tanrei-button>
   <tanrei-button variant="outlined" size="small" disabled>إلغاء</tanrei-button>
   ```

4. أعطِ كلمات منتجك. ليس للمكوّن كلمات خاصة به: نص وسم المطلوب أو الاختياري، واسم زر الإغلاق، وما شابههما، كلها كلمات منتجك. ولتبدأ بإنجليزية بسيطة لها كلها، استورد حزمة الكلمات الإنجليزية مرة واحدة:

   ```js
   import '@tanrei/web/words/en';
   ```

   ولتغيّر أيًّا منها، أو لتعطي كلمات لغة أخرى، استدعِ `setWords()` بعدها. الكلمة التي تعطيها تغلب كلمة الحزمة، والكلمة المعطاة على العنصر تغلب الاثنتين.

   ```js
   import { setWords } from '@tanrei/web';

   setWords({ requiredText: 'Mandatory' });
   setWords({ requiredText: 'مطلوب', optionalText: 'اختياري', closeLabel: 'إغلاق' }, { lang: 'ar' });
   ```

   يعمل المكوّن حتى من دون الحزمة ومن دون كلماتك، ويخبرك في وحدة التحكم (console) بالكلمة التي تنقصه. انظر [الكلمات](/ar/foundations/words/).

</Steps>

## بيان العناصر

تقرأ المحررات ووكلاء البرمجة عناصر الحزمة من [بيان العناصر المخصّصة](https://github.com/webcomponents/custom-elements-manifest) الخاص بها، `@tanrei/web/custom-elements.json`: كل عنصر بسماته وخصائصه وأحداثه وفتحاته وأجزائه، ولا شيء لا يصل إليه المنتج. ولا يحوي `@tanrei/web/custom-elements/<id>.json` إلا العناصر التي يتضمنها النظام `<id>`، فلا تقترح الأداة التي تعمل في نظام واحد شيئًا غيرها.

## السمة والتباين

تستخدم قيم الرموز الدالة `light-dark()`، فتتبع قيمة `color-scheme` للعنصر الذي تُستخدم عليه. ومعنى ذلك افتراضيًّا أنها تتبع إعداد نظام التشغيل، وأن `prefers-contrast: more` ينقلها إلى المخطط اللوني العالي التباين.

للتحكم فيها بنفسك، عيِّن خاصيتَي HTML التاليتين:

```html
<!-- فرض سمة على الصفحة أو على أي شجرة فرعية -->
<html data-tanrei-theme="dark">

<!-- فرض مستوى تباين على الصفحة: "medium" أو "high" -->
<html data-tanrei-contrast="high">
```

<Callout>
  تعمل الخاصيتان كلتاهما على `<html>` أو على أي شجرة فرعية. تعلن ورقة الأنماط المولَّدة مجموعة الرموز كاملة على `:root, [data-tanrei-contrast]`، ولذلك فإن وضع `data-tanrei-contrast` على عنصر داخلي يعيد حساب رموز المكوّنات داخله وفق مستوى التباين ذاك، لا ألوان النظام وحدها.
</Callout>

### احتفظ بالسمة التي يختارها الشخص

إن كان الناس يختارون سمة في منتجك، فاحفظ اختيارهم وضعه على `<html>` قبل أن تُرسم الصفحة أول مرة: فإن وضعه سكربت يعمل بعد ذلك، عرضت الصفحة سمة النظام لإطار واحد أولًا. والوحدة `@tanrei/web/theme-script` تفعل الأمرين. الدالة `themeScript()` سكربت صغير يُكتب مضمَّنًا في `<head>` قبل أوراق الأنماط، والدالة `saveTheme()` تحفظ الاختيار وترسمه في الحال.

```js
import { loadTheme, saveTheme } from '@tanrei/web/theme-script';

saveTheme('dark'); // 'light' أو 'dark'، أو 'system' للعودة إلى اتباع نظام التشغيل
loadTheme();       // المحفوظ: 'light' أو 'dark' أو 'system'
```

في Next.js (App Router)، اكتبه مضمَّنًا في التخطيط الجذري. والخاصية `suppressHydrationWarning` موجودة لأن السكربت يغيّر سمة من سمات `<html>` قبل أن يرطّبه React.

```tsx
// app/layout.tsx
import { themeScript } from '@tanrei/web/theme-script';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en" suppressHydrationWarning>
      <head>
        <script dangerouslySetInnerHTML={{ __html: themeScript() }} />
      </head>
      <body>{children}</body>
    </html>
  );
}
```

وفي Astro، اكتبه مضمَّنًا في التخطيط:

```html
---
// src/layouts/Layout.astro
import { themeScript } from '@tanrei/web/theme-script';
---
<html lang="en">
  <head>
    <script is:inline set:html={themeScript()} />
  </head>
  <body><slot /></body>
</html>
```

## الرموز في CSS الخاص بك

كل رمز خاصية مخصصة تحمل اسم مساره: `tanrei.sys.color.primary` يصبح `--tanrei-sys-color-primary`.

```css
.panel {
  background: var(--tanrei-sys-color-surface-container-low);
  border-radius: var(--tanrei-sys-shape-corner-medium);
  box-shadow: var(--tanrei-sys-elevation-level1);
  font: var(--tanrei-sys-typescale-body-font);
}
```

لتضبط رمزًا من سكربت، استخدم `setTokens()` من `@tanrei/web`: `setTokens({ '--tanrei-sys-color-primary': '#0b57d0' })` على الجذر، أو مع `{ on: element }` لجزء من الصفحة. فضبط رمز واحد وحده على الجذر بالدالة `style.setProperty()` يجعل Safari يعيد حساب أنماط الصفحة كلها لثوانٍ؛ أما `setTokens()` فتكتبه بطريقة لا يحدث معها ذلك.

## أنماط النص

تُسمّى أنماط النص بحسب المستوى (`heading-2` هو `h2`، و `body` هو `p`، و `label` هو النص على عنصر التحكم)، وكل نمط منها مجموعة من الخصائص المخصصة: `--tanrei-sys-typescale-<role>-font` صيغةً مختصرة، ومعها `-font-family` و `-font-size` و `-font-weight` و `-line-height` و `-letter-spacing` و `-font-weight-emphasized`. وتوجد ورقتا أنماط اختياريتان تطبّقانها على العناصر عنك:

```js
import '@tanrei/web/text.css';   // .tanrei-text-<role>, .tanrei-text-emphasized
import '@tanrei/web/prose.css';  // h1–h6, p, small, code, pre inside .tanrei-prose
```

```html
<h2 class="tanrei-text-heading-2">قسم</h2>
<p class="tanrei-text-body">نص متصل فيه <strong class="tanrei-text-emphasized">توكيد</strong>.</p>
<article class="tanrei-prose"><!-- Markdown بعد تحويله --></article>
```

يرسم الصنف `.tanrei-text-emphasized` الدور الذي يقع فيه بوزنه مضافًا إليه درجة التوكيد الخاصة بفئته؛ فهو وزن وليس دورًا آخر. الأدوار الستة عشر ومقابلتها بالعناصر في صفحة [الطباعة](/ar/foundations/typography/).

## الخطوط

يطلب السلّم الطباعي الخطوط Inter و Noto Sans JP و Noto Sans و Roboto Mono (`--tanrei-ref-typeface-{brand,plain,mono}` في `tokens.css`؛ ويطبع الأمر `tanrei build` القائمة لأي نظام)، وتطلب الأيقونات الخط Material Symbols Rounded، وكل ذلك يعود إلى خطوط النظام عند غيابه. لا يضمّ Tanrei ملفات خطوط؛ حمِّلها بنفسك تحت أسماء عائلات الخطوط هذه بالضبط: من Google Fonts، أو من حزم `@fontsource-variable/*` (وهذه تسجّل الخطوط باسم `Inter Variable` وما شابه؛ فأعلن `@font-face` خاصًّا بك بالاسم المجرّد يشير إلى ملفاتها، كما يفعل هذا الموقع).

## الأيقونات

```js
import '@tanrei/web/icons.css';
```

```html
<tanrei-button><span slot="icon" class="tanrei-icon" aria-hidden="true">add</span>إضافة</tanrei-button>
```

يرسم الصنف `.tanrei-icon` أيقونة باسمها في [Material Symbols](https://fonts.google.com/icons) بوزن الأيقونات المحدَّد في النظام، ويأخذ حجمه من موضعه. لا تختار أنت بين الأيقونة المحدَّدة الأطراف والمعبَّأة أبدًا: انظر [الأيقونات](/ar/foundations/icons/).

يضمّ ملف Material Symbols Rounded الكامل كل الرموز بكل الأوزان والتعبئات والدرجات والأحجام البصرية: 5.4 ميغابايت، وقد تنتظره صفحة على اتصال بطيء نصف دقيقة. حمِّل فقط الرموز التي يرسمها منتجك. يطبع الأمر `tanrei build` أسماء الرموز التي قد ترسمها مكوّنات Tanrei بنفسها (سهم الشيفرون، وعلامة الاختيار، وعلامة الإغلاق في زر الإغلاق…) وقيم المحاور التي يرسم بها نظامك الأيقونات؛ أضف أسماءك إلى هذه القائمة. عند التحميل من Google Fonts، مرِّر الأسماء مرتّبةً أبجديًا في `icon_names=` واكتب المحاور نطاقاتٍ في `family=` (`Material+Symbols+Rounded:opsz,wght,FILL,GRAD@20..48,300..500,0..1,0` للنظام الافتراضي). وإن كنت تقدّم الملف بنفسك، فاقتطعه بأداة تقتطع مجموعات فرعية تُبقي ميزات الحروف المركّبة في الخط (`rlig` و`rclt`) والتعبئتين معًا؛ وهذا الموقع يرسم أيقوناته من ملف كهذا. وفي الحالتين، سجِّل خط الأيقونات مع `font-display: block`: إلى أن يصل الملف تبقى الأيقونة غير مرئية، ولا يظهر اسمها حروفًا أبدًا.

## دعم المتصفحات

تعتمد الرموز على `light-dark()` وعلى طبقات التتالي (cascade layers)، وهما متاحتان في الإصدارات الحالية من Chrome و Edge و Firefox و Safari.
