يأتي Tanrei مع نظامه الافتراضي `tanrei` وإعدادين جاهزين: `m3-like` و`cupertino`. الإعداد الجاهز [طبقة نظام تصميم](/ar/foundations/design-systems/#الأنظمة-المضمَّنة) مثل التي تكتبها بنفسك: يعطي مكوّنات Tanrei قيم نظام تصميم آخر، ويحدّد أيّ المكوّنات، وأيّ قيم `variant` لها، يتضمّن. استخدمه كما هو، أو نقطةَ بداية [لنظام التصميم الخاص بك](/ar/getting-started/your-design-system/).

## استخدام إعداد جاهز على الويب

<Steps>

1. حمّل الرموز، ثم ورقة أنماط الإعداد الجاهز. تنطبق رموزه حيث توضع سمته.

   ```js
   import '@tanrei/web/tokens.css';
   import '@tanrei/web/systems/m3-like.css';
   ```

2. ضع السمة على `<html>` أو على أي جزء من الصفحة: يمكن لعدة أنظمة أن تجتمع في صفحة واحدة.

   ```html
   <html data-tanrei-system="m3-like">
   ```

3. سجّل مكوّنات الإعداد الجاهز بمدخله، بدلًا من `@tanrei/web`. يسجّل المكوّنات التي يتضمّنها الإعداد الجاهز ولا شيء غيرها.

   ```js
   import '@tanrei/web/m3-like';
   ```

4. حمّل خطوطه بأسماء العائلات التي تستخدمها رموزه، وهي مسرودة أدناه. لا يضمّ Tanrei أي ملف خط: راجع [الخطوط](/ar/getting-started/web/#الخطوط).

</Steps>

ما يتضمّنه الإعداد الجاهز مسرود في بيان مكوّناته، `@tanrei/web/systems/<id>.components.json`، الذي تقرؤه المحرّرات ووكلاء البرمجة. في هذا الموقع، اختر نظام تصميم بجانب [قائمة المكوّنات](/ar/components/) أو في أعلى الشريط الجانبي، فتعرض القوائم ما يتضمّنه ذلك النظام فقط.

## خذ مكوّنًا واحدًا من إعداد جاهز إلى نظامك الخاص

المكوّن الذي يتضمّنه إعداد جاهز ولا يتضمّنه النظام الافتراضي — قائمة FAB في `m3-like`، أو الزر المقسَّم — ليس بعيدًا عن متناول منتج مبني على النظام الافتراضي. اكتب طبقة توسّع `tanrei`، وأدرج فيها المكوّن، واستورد وحدته الخاصة. عندها يُرسم المكوّن برموز نظامك: رموزه تشير إلى رموز نظامك، فتبدو قائمة FAB المأخوذة بهذه الطريقة مثل بقية منتجك، ولا تأتي معها أي قيمة من قيم الإعداد الجاهز.

<Steps>

1. أدرج المكوّن في طبقتك (`design/acme.system.json`؛ راجع [نظام التصميم الخاص بك](/ar/getting-started/your-design-system/)). المكوّن الذي يقع في طبقة إعداد جاهز يسمّي تلك الطبقة (`from`)؛ والمكوّن الذي يستبعده النظام الافتراضي يُذكر باسمه وحده.

   ```json
   {
     "id": "acme",
     "extends": "tanrei",
     "components": {
       "include": [{ "name": "fab-menu", "from": "m3-like" }, "segmented-button"]
     }
   }
   ```

2. ابنِ. يكتب `npx tanrei build` ورقة أنماط نظامك، وفيها رموز المكوّنات المُدرجة مقيَّمةً من رموزك، وبيان مكوّناتك الذي يسردها.

3. حمّل ورقة أنماطك، وضع سمتك، وسجّل مكوّنات النظام الافتراضي والمكوّنات التي أخذتها.

   ```js
   import '@tanrei/web/tokens.css';
   import './styles/acme.css';
   import '@tanrei/web';
   import '@tanrei/web/components/fab-menu';
   import '@tanrei/web/components/segmented-button';
   ```

   ```html
   <html data-tanrei-system="acme">
   ```

</Steps>

المكوّن المستخدَم تحت نظام لا يتضمّنه يُرسم مع ذلك، ويذكر ذلك في وحدة التحكم في بناء التطوير. وتذكر صفحة كل مكوّن أيّ الأنظمة تتضمّنه، وما الذي تستخدمه الأنظمة الأخرى بدلًا منه.
