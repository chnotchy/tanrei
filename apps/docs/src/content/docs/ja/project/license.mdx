## ライセンス

Tanrei は **{config.license}** ライセンスのもとで提供されます。このライセンスの条件に従って、商用・非商用のプロダクトで使用し、改変し、再配布できます。全文はリポジトリの `LICENSE` ファイルに、必要な告知は `NOTICE` にあります。
