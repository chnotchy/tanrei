コントロールや行の高さは、3 つの値で決まります。**密度**と**最小ターゲット**はデザインシステム全体のもので、プロダクトはそれぞれをレイヤで一度だけ設定します。**サイズ**は 1 つのコンポーネント、またはそのグループのもので、ボタンは置かれた場所で small、medium、large のどれかになります。

## 密度は 1 つの数

`tanrei.dial.density` はただの数で、既定値は 1 です。1 より小さければコントロールと行は詰めて描かれ、1 より大きければ余裕が増えます。動かすのはブロック方向だけです。

- **動かすもの**：コントロールと行の高さ、高さを持つ箱のブロック方向のパディング（それぞれ、箱の高さが動いた分の半分だけ動きます）、そして説明リストの項目どうしやタイムラインの項目どうしのような、コレクションの行と行の間隔。
- **動かさないもの**：テキストスタイル、アイコンサイズ、角、そして行を横切る方向の余裕。インライン方向のパディング、行に沿った間隔、インデントは、余白のダイヤル `dial.space.unit` に従います。

密度に従う高さはどれも、サイズ単位のグリッド（`dial.size.unit`、既定では 4px）に丸められ、ちょうど中間の値は上に丸められます。

コンポーネントごと、ページの一部ごとの密度はありません。[ナビゲーションドロワー](/ja/components/navigation-drawer/)だけは、`density` という名前の独自の選択肢 `regular` と `compact` を持ち、行のトークンの 2 つの組のどちらを使うかを選びます。どちらの組の高さも、この数に従います。

## サイズの段

段は `tanrei.sys.control.height.*` の 5 つの高さで、コントロールのサイズはここを読みます。それぞれ、サイズ単位に段の係数と密度を掛け、グリッドに乗せた値です。いくつかの密度での高さを、トークン自身のルールから計算して示します。

<DensityHeights group="sys.control.height" densities={[0.75, 0.9, 1, 1.25, 1.5]} source="tokens/sys/measure.tokens.json" />

多くのコンポーネントが高さをこの段から読み、同じ段を読むもの同士は、どの密度でも同じ高さのままです。Button の `small`、`medium`、`large` は、small、medium、large の段を読みます。段そのものには下限がありません。`extra-small` は、タグやキーボードショートカットのように、誰も押さないもののための段だからです。

## 最小ターゲット

`tanrei.sys.target.minimum` は、人が押すものを描く最小の高さで、アイコンだけのコントロールでは最小の幅でもあります。押せる箱や行の高さはどれもこれを下限として導出されるので、どの密度でも、どのサイズでも、これより低くは描かれません。これは開発者が決める値で、どのダイヤルも拡大縮小しません。下限が、下限をかける相手と一緒に縮んでしまえば、下限の意味がないからです。

既定のシステムでは、最小は 36 で、ポインターでも指でも同じです。Button の高さを見ると、その働きがわかります。かっこ内の値はサイズと密度が与える高さで、その前の高さが、最小ターゲットによってボタンが保たれている高さです。

<DensityHeights group="comp.button.container.height" densities={[0.75, 0.9, 1, 1.25, 1.5]} source="tokens/comp/button.tokens.json" />

さらに 2 つの値が、押されたことをどれだけの範囲で受け取るかを決めます。指では `sys.target.touch`、細かいポインターでは `sys.target.pointer` です。どちらも既定では最小ターゲットと同じなので、1 つの値で 3 つすべてが決まります。プラットフォームのガイドラインに従うシステムは、これらを大きくします。そのとき、単独で置かれたコントロールは、描いた範囲を越えてその広い範囲から押されたことを受け取り、隣と接する行はその高さで描かれます。チェックボックスの箱や小さいチップのように、ターゲットより小さく描かれるしるしは、大きさを変えずに、ヒット領域をターゲットまで広げます。同梱の各システムの設定は次のとおりです。

<SystemValues tokens={['sys.target.minimum', 'sys.target.touch', 'sys.target.pointer']} />

ビルドはすべてのシステムを確かめます。3 つのどれも 24px（WCAG 2.5.8）を下回らないこと、`touch` と `pointer` が最小ターゲットを下回らないこと、密度が 0 より大きいこと、そして下限のある高さが最小ターゲットを下回らないことです。プロダクト自身のレイヤがターゲットを 24px 未満にした場合は、警告として知らされます。押されたことを受け取る範囲が最小ターゲットを下回る場合と、密度が 0 以下の場合は、どのシステムでも拒否されます。

## レイヤでの設定

どちらも、レイヤが理由を添えて設定するトークンです。

```json
"tokens": {
  "tanrei.dial.density": { "$value": 0.9, "reason": "An editor people look at all day: rows a little closer." },
  "tanrei.sys.target.minimum": { "$value": { "value": 32, "unit": "px" }, "reason": "Used with a mouse; 32 is the least we draw." }
}
```

Web では高さがダイヤルの CSS 式になっているので、ルート要素に `--tanrei-dial-density` を設定すると、ビルドし直さなくても、すべての高さが一度に動きます。[Theme Studio](/ja/foundations/theme-studio/) では、「サイズ」の行に密度、サイズ単位、最小ターゲットがあります。

## コンテナに設定するサイズ

サイズは、コンポーネントが置かれる場所で設定します。Web では、ボタングループの `size` を設定すると、それが中の Button のうち自分のサイズを持たないすべてのサイズになります。

```html
<tanrei-button-group size="small">
  <tanrei-button variant="outlined">Cancel</tanrei-button>
  <tanrei-button variant="filled">Publish</tanrei-button>
  <tanrei-button variant="text" size="medium">Details</tanrei-button>
</tanrei-button-group>
```

- **コンポーネント自身のサイズが優先されます。** 上の 3 つめの Button は medium です。
- **渡されるのは、設定されたサイズだけです。** `size` のないグループは何も渡さないので、中の Button はそれぞれ自分の既定である medium か、グループを囲むコンテナが設定するサイズで描かれます。コンテナが入れ子になっているときは、サイズを設定しているいちばん近いコンテナで決まります。
- **コンポーネントにないサイズは、いちばん近いサイズになります。** 近さは extra-small、small、medium、large、extra-large の段の並びで測り、同じだけ近いものが 2 つあれば大きいほうになります。
- **ボタングループとツールバーは、サイズによって自分では何も描き変えません。** 間隔、角、区切り線はバリアントのとおりのままで、描かれる高さの項目を囲みます。

コンテナから渡されたサイズで描かれるコンポーネントも、自分のサイズで描かれるときと同じように、密度と最小ターゲットに従います。コンテナのサイズを変えたり、コンポーネントをコンテナに入れたり出したりすると、その場で新しいサイズで描かれます。

### サイズを渡すもの、受け取るもの

設定されたサイズを中のものに渡すコンテナは 3 つです。

- [ボタングループ](/ja/components/button-group/)は、中の Button に渡します。
- [ツールバー](/ja/components/toolbar/)は、グループの中かどうかにかかわらず Button とメニュー付きボタンに渡し、オーバーフローボタンにも渡します。
- [リスト](/ja/components/list/)は、中のリスト行に渡します。

次のコンポーネントは、自分のサイズを設定していなければ、これらのうちいちばん近いコンテナのサイズを受け取り、サイズを設定するコンテナがなければ medium で描かれます。[Button](/ja/components/button/)、[メニュー付きボタン](/ja/components/button-with-menu/)、[コピーボタン](/ja/components/copy-button/)、[リスト行](/ja/components/list-row/)、そして自分の行や部分をすべてそのサイズで描く[リスト](/ja/components/list/)、[ツリービュー](/ja/components/tree-view/)、[アコーディオン](/ja/components/accordion/)、[目次](/ja/components/table-of-contents/)、[説明リスト](/ja/components/description-list/)、[テーブル](/ja/components/table/)です。

サイズが届くのはそこまでです。アコーディオン、説明リスト、テーブルは、中に置かれたものにサイズを渡しません。テーブルのセルに置いた Button は、自分のサイズか、テーブルを囲むコンテナのサイズで描かれます。また、コンテナからサイズをまったく受け取らないコンポーネントもあります。

- [メニュー](/ja/components/menu/)（コンテキストメニューや[メニューバー](/ja/components/menubar/)のメニューを含みます）、[検索](/ja/components/search/)のビュー、[セレクト](/ja/components/select/)と[コンボボックス](/ja/components/combobox/)のリスト。どれもページの上に、周りのコントロールとは別に開くので、ツールバーを small にしても、そこにある Button が開くメニューは小さくなりません。メニューと検索は、自分の `size` を設定しなければ medium です。セレクトとコンボボックスの選択肢は、ボックスのサイズに従います。
- ツールバーの中のセレクト、数値入力、テキスト入力、スライダー。どれも指定したサイズのままです。
- [タイムライン](/ja/components/timeline/)。サイズはテキストの大きさを表します。
