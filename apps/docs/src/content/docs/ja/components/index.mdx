Tanrei のインベントリは {inventory.length} のコンポーネントファミリーからなります。各プラットフォームで何を提供しているかは[ステータスページ](/ja/status/)にあります。コンポーネントは仕様が書かれた時点でここにページができます。「計画中」と書かれた項目は仕様がまだなく、リンクになっていません。各項目の数字は、実装のあるプラットフォーム数です。

コンポーネントのページは、どれも同じ 4 つのセクションで構成されています。

1. **概要** — 何のためのコンポーネントか、どこで使えるか。
2. **仕様** — 構成要素、プロパティ、状態、振る舞い、トークン、プラットフォーム別の名前対応。コンポーネントの仕様ファイルから描画しています。
3. **ガイドライン** — いつ、どのように使うか。
4. **アクセシビリティ** — ロール、キーボード操作、ラベル付け。
