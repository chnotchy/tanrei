## ガイドライン

### 使う場面

本当の最小値と最大値がある範囲の中で、ある量がどこにあるかを示すときに使います。割り当てに対するストレージの使用量、電池の残量、部屋の予約済みの席、新しいパスワードの強さなどです。示すのは量で、何かが進行中なわけでも、いつか終わるわけでもありません。

アップロード、インポート、時間のかかる保存のように、実行中のタスクには、代わりに[プログレスインジケーター](/ja/components/progress-indicator/)を使います。見た目は同じですが、支援技術は何かが進行中だと伝えます。メーターはそう伝えてはいけません。メッセージの件数のように、意味のある最大値がない値はどちらでもなく、テキストで示します。

### バリアントの選び方

| バリアント | 用途 |
| --- | --- |
| Linear | ページやセクションに属する量。設定ページのストレージ、カードの中の割り当て、プランの一覧の行など。バーはレイアウトが与える幅いっぱいに伸びます。 |
| Circular | 狭い場所や、テキストの横での量。ステータスバーの電池、デバイスの一覧の行など。リングの大きさは固定です。 |

### サイズの選び方

| サイズ | 既定のシステムでのバーの太さ / リングの大きさ | 用途 |
| --- | --- | --- |
| Small | 2 / 16 | 密度の高い行、小さなテキストの横。 |
| Medium | 4 / 24 | ほとんどの場所。既定値です。 |
| Large | 8 / 40 | アカウントのストレージのページのように、その画面の主役である量。 |

サイズ、トラック、既定の色はプログレスインジケーターと同じなので、メーターとプログレスインジケーターを並べてもそろいます。デザインシステムは、メーター自身のトークンで、メーターだけを変えられます。

### ステータスの選び方

値が何を意味するかを、メーターは決めません。多いほうが良いのか悪いのかは、プロダクトが知っていることです。ストレージがほぼいっぱいなら warning、パスワードがほぼ最大の強さなら success です。ステータスはプロダクトが計算して渡します。ステータスの名前は、タグとスナックバーと同じです。

| ステータス | 用途 |
| --- | --- |
| Default | 何も言う必要のない量。ほとんどのメーターはこれです。 |
| Info | 知っておく価値はあるが、何も求めない量。まもなくリセットされる割り当てなど。 |
| Success | あるべきところにある量。強いパスワードなど。 |
| Warning | 近いうちに注意が必要な量。ほぼいっぱいのストレージや、残りわずかの電池など。 |
| Error | すでに何かを止めている量。いっぱいになったストレージなど。 |

ステータスが変えるのはインジケーターの色だけです。その意味は言葉でも伝えます。値のテキストと、メーターの横のテキストです。

### 推奨

- 何を測っているかを表すラベルを付けます。「メーター」ではなく「ストレージの使用量」です。横にキャプションを表示するなら、同じ言葉を使います。
- パーセントが自然な読み方でないときは、値のテキストを使います。「15 GB 中 9.3 GB」「50 席中 37 席」「強い」などです。
- ステータスに意味があるときは、値のテキストにも入れます。「残りわずか：15 GB 中 12.8 GB」のようにします。

### 非推奨

- 実行中のタスクに使わない。それはプログレスインジケーターです。
- ステータスの色だけに頼らない。色が見えない人にも、ストレージがほぼいっぱいだと伝わらなければなりません。
- 範囲の外の値を示さない。メーターは範囲に収めて描き、伝えるので、聞こえる数は手元の数と違ってしまいます。

## アクセシビリティ

<ComponentAccessibility name="meter" />

### コンポーネントが担うこと

- メーターのロールを公開し、ラベルを名前にします。範囲、現在の値（範囲に収めたもの）、値のテキストがあればそれも公開します。ビジー状態や、タスクが進行中であることは伝えません。
- フォーカスを受け取らず、変化を自分から読み上げません。支援技術は、利用者がたどり着いたときに現在の値を読みます。
- ステータスをそれだけで読み上げることはありません。変わるのは色だけです。
- 値が変わるとインジケーターの端が動き、ステータスが変わると色がフェードします。動きを減らす設定のときは、端はすぐに動き、色だけがフェードします。
- 強制カラーモードでは、ステータスにかかわらず、トラックは細い縁に、インジケーターは塗りつぶしになり、どちらもテキストの色で描かれます。値は、インジケーターの終わる位置で読み取れます。
- 空のラベル、範囲の外の値、数でない値、未知の `size`、`variant`、`separation`、`status` は、デバッグビルドで報告されます。

### 利用者がすること

- ステータスが意味することを言葉で伝えます。値のテキストと、メーターの横のテキストです。
- ストレージがいっぱいになったときのように、重要な変化は自分で知らせます。ライブリージョンのメッセージか、利用者が目にする通知です。メーターは知らせません。
- インジケーターの色（既定と 4 つのステータス）を変えるときは、どれもトラックと背後のサーフェスに対して 3:1 以上を保ちます。値は、インジケーターとトラックの接する位置で読み取られます。既定のシステムでは、5 色ともライトで 4.6:1 以上、ダークで 7.3:1 以上です。
