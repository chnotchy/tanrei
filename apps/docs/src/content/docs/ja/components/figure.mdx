図は、読むものではなく見るものをひとつ見せます。記事の中の画像、レポートのグラフ、設定の結果のプレビュー、見本などです。それを周りから切り離し、何であるかを伝えます。このサイトで、動く例を囲んでいる枠も図です。

図はカードではありません。カードは、ひとつの主題についてのコンテンツとアクションをまとめるもので、全体を押せることもあります。図はひとつのものを見せるだけで、押せることはなく、キャプションは枠の外に置きます。

Web では、ネイティブの `<figure>` を `<tanrei-figure>` で囲みます。この要素はシャドウルートを持たないので、図とその `<figcaption>` は文書自身のものです。スクリプトがなくても、クローラーにも、リーダーモードでも読め、名前はブラウザーが付けます。ほかのプラットフォームはまだ実装していません。

`@tanrei/web/figure.css` は、スクリプトが動く前に図全体を描きます。そのため、図の多いページでも、スクリプトが届いたときにレイアウトが動きません。要素自身も、同じスタイルシートをページに加えます。

### 書くもの

| パーツ | Web での書き方 |
| --- | --- |
| 枠 | `<div data-part="frame">`。`<figure>` の最初の子で、ヘッダー、ステージ、アタッチメントを収めます。 |
| タイトル | 枠の `<header>` の中の、`data-part="title"` を持つ要素。`<p>` か、ページのアウトラインに必要な見出しです。 |
| アクション | `<header>` の中の `<div data-part="actions">`。利用者側のコントロールを囲みます。 |
| ステージ | `<div data-part="stage">`。見せるものを囲みます。 |
| アタッチメント | ステージの後ろに置く、`data-part="attachment"` を持つ要素。コードブロック、テーブル、説明リストなど、どの要素でもかまいません。 |
| キャプション | 枠の後ろの `<figcaption>`。 |

ステージ以外のパーツは省略できます。ステージの要素の代わりに、`<img>`、`<picture>`、`<video>`、`<svg>`、`<canvas>` を 1 つだけ置くこともできます。Markdown レンダラーが書き出す `<figure><img …><figcaption>…</figcaption></figure>` のように、枠の要素がまったくない図も描かれます。その場合は、画像自体が枠になります。

### 要素が組み立てる図

`<figure>` を含まない `<tanrei-figure>` には、要素が定義されたときに `<figure>` が作られます。子はステージに入ります。ただし、`slot`（`title`、`actions`、`caption`、`attachment`）でパーツを指定した子は、そのパーツになります。`headline` 属性と `caption` 属性は、タイトルとキャプションとして書き出されます。

```html
<tanrei-figure headline="バリアント" caption="Filled のボタン。">
  <tanrei-button variant="filled">保存</tanrei-button>
</tanrei-figure>
```

この形は短く書けますが、描かれるのはスクリプトが動いた後です。ページのレイアウトを動かしたくない場合は、パーツを自分で書いてください。要素の子を自分で管理するフレームワーク（React）で使う場合も同じです。この形では、要素が子を移動するからです。

## ガイドライン

### 3 つの見た目

| `variant` | 描き方 | 用途 |
| --- | --- | --- |
| `outlined`（既定） | 細い線で囲んだサーフェス。 | 見本、動く例、図解。 |
| `filled` | 控えめなトーンの塗りで、縁はありません。 | すでに線の多いページ。影のあるものを置く下地。 |
| `plain` | 塗りも、縁も、パディングも、線もありません。 | それ自体が枠になる画像。グリッドに並べる見本。 |

Outlined は、中を空のままにせず、サーフェスの色で塗ります。そのため、図をどのパネルに置いても、中に置いた利用者側のコンポーネントは、トークンで確かめられているコントラストを保ちます。

### タイトルは上、キャプションは下

- `title`（Web では `headline` 属性）は、枠の中のヘッダーに置く短い 1 行です。見せているものの名前を書きます。
- `caption` は枠の下に、先頭側の端にそろえて、セカンダリーのテキストとして描きます。折り返し、途中で切れることはありません。
- 位置を選ぶ設定はありません。ステージの上のテキストはタイトルで、キャプションの場所は 1 つだけです。
- タイトルはプレーンテキストで、見出しではありません。ページのアウトラインのためにそこに見出しが必要なときは、`data-part="title"` を付けた見出しを書きます。図はそれをタイトルのスタイルで描き、見出しのロールとレベルを保ちます。

### コントロールと、つながったブロック

- アクションは、ヘッダーの末尾側に置く利用者側のコントロールです。バリアントやテーマを切り替える、別の場所で開く、といったものです。図はそれらを 1 行に並べるだけで、ほかには何もしません。行の幅が足りなくなると、タイトルの下に移ります。
- アタッチメントは、枠の中でステージの下に置く利用者側のブロックです。例のもとになったコードや、グラフのデータなどです。

| `separation` | 描き方 |
| --- | --- |
| `auto`（既定） | デザインシステムが選んだもの。既定のシステムでは線です。 |
| `divider` | ヘッダーの下とアタッチメントの上に線を描きます。アタッチメントは枠にぴったり付きます。 |
| `gap` | 線は描きません。アタッチメントは枠の内側に 8 だけ入った位置に、自身の形のまま置かれます。 |

### ステージ

- `inset`（既定は true）は、ステージに上下 32、左右 24 のパディングを付けます。Web では `flush` を付けるとパディングがなくなり、画像、グラフ、地図などが枠の端まで届いて、枠の角丸で切り取られます。
- 画像は、縦横比を保ったまま縮小されます。拡大されることはありません。
- 縮められないコンテンツは、ステージの中で横にスクロールします。図が、自分の置かれたコンテナより広くなることはありません。
- 枠のあるステージより狭いコンテンツは、中央に置かれます。Plain では、テキストの端から始まります。
- ステージの高さは、コンテンツの高さです。その中に複数の例をどう並べるかは、利用者側のレイアウトで決めます。

### ページの中で

- 図は与えられた幅いっぱいに広がり、外側に余白を持ちません。プローズの中では、ブロックとしての余白が付き、プローズの幅いっぱいに広がります。キャプションは、テキストのブロックと同じように行長の上限に収まります。
- 複数の図を横に並べるときは、利用者側でグリッドを組みます。図はそのセルいっぱいに広がります。

### 推奨

- キャプションには、その図で何を伝えたいかを書きます。「グラフ」ではなく「すべての地域で売上が増えた」のようにします。
- 画像には、画像自身の代替テキストを付けます。キャプションはその代わりになりません。
- 従うべき例や避けるべき例は、キャプションの先頭に小さいタグを置き、「推奨」「非推奨」のように言葉で示します。

### 非推奨

- 関連するコンテンツとアクションをまとめるために図を使わない。それは[カード](/ja/components/card/)です。
- 図を押せるようにしない。何かを開く画像にしたいときは、画像をリンクで囲みます。
- 例が正しいか誤りかを伝えるために枠に色を付けない。図にステータスはありません。

## アクセシビリティ

<ComponentAccessibility name="figure" />

### コンポーネントが担うこと

- ネイティブの `<figure>` は図（figure ロール）のままです。名前はタイトルで、タイトルがなければキャプションです。両方あるときは、タイトルが名前、キャプションが説明になり、キャプションはその場所でも読み上げられます。
- `label` は、タイトルもキャプションも描かない図に名前を付けます。画面には描かれず、タイトルかキャプションがあるときは無視されます。
- ステージが横にスクロールしている間、ステージはフォーカスの順序で 1 つの止まる位置になります。順序は中のものより前で、図の名前を持つグループとして伝わります。矢印キーでスクロールし、Home と End でそれぞれの端へ移ります。スクロールしないステージは、フォーカスが止まる位置を増やしません。
- フォーカスリングはステージの端の内側に描くので、何にも切り取られません。
- ヘッダー、ステージ、アタッチメント、キャプションの中のものは、すべてそのまま操作でき、フォーカスの順序も変わりません。
- テキストを 200% にすると、タイトルとキャプションは大きくなって折り返し、アクションはタイトルの下に移ります。
- 右から左のレイアウトでは、ヘッダーが左右反転し、キャプションは右から始まります。ステージで見せているものは反転しません。
- 強制カラーモードでは、Outlined と Filled にテキストの色の縁が付きます。Plain には付きません。
- 名前のない図、ステージが空の図、未知のバリアントや区切り方は、デバッグビルドで報告します。

### 利用者側で行うこと

- すべての図に、タイトル、キャプション、`label` のいずれかを付けます。
- ステージの中の画像には、画像自身の `alt` を付けます。画像が伝えることをキャプションがすべて述べているときは、画像を装飾として扱います（`alt=""`）。
- 動く例は、操作できるままにしておきます。図がコンテンツを隠したり、画像に変えたりすることはありません。
