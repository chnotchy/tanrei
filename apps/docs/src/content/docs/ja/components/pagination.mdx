このページの末尾にあるページネーションも同じコンポーネントです。

ガイドの章や連載の記事のように、それぞれのページにタイトルがある並びをめくるためのものです。番号でめくる形（検索結果のページなど）は、同じコンポーネントに後から加える形で、まだ仕様がありません。

### 使い方

Web では、ページネーションは要素ではなく、プロダクト側の `nav` とアンカーに付けるクラスです。アンカーは文書の中にあるので、スクリプトが動く前からリンクとして働き、クローラーからも、ページ内のアンカーを扱うルーターからも見つけられます。コンポーネント全体を、スタイルシートだけで描きます。

SwiftUI、Compose、Flutter、React Native は計画中です。このページの冒頭で各プラットフォームに添えた名前は仕様が定めたもので、まだ提供していません。React にもまだ `Pagination` コンポーネントはないので、クラスを付けたマークアップを使ってください。

- **項目は 1 つのリンク**で、全体が押せます。輪郭線のあるコンテナとして描きます。輪郭線は細い線で、塗りはなく、タイトルはテキストの色です。下線は引きません。輪郭線と矢印と置かれた場所で、周りのテキストと見分けられるからです。
- **矢印はコンポーネントが描きます**。前の項目の先頭側の端に `arrow_back`、次の項目の末尾側の端に `arrow_forward` です。`icons.css` が必要です。
- **同じ幅の 2 列。** 最初のページでは先頭側の列が空になり、次の項目はほかのページとまったく同じ場所に置かれます。
- **縦に並ぶ形。** ページネーションの幅が、項目の最小幅 2 つ分と隙間の合計（既定のシステムでは 496）に満たないとき、項目は前を上、次を下にして縦に並びます。これを決めるのはウィンドウの幅ではなく、コンポーネント自身の幅です。
- **タイトルは折り返し、途中で切れません。** 横に並んだ 2 つの項目は、高いほうの高さにそろいます。タイトルのない項目は、方向だけをタイトルのスタイルで示します。
- **右から左**のレイアウトでは、前の項目が右に置かれて矢印は右を指し、次の項目が左に置かれて矢印は左を指します。読む順序とフォーカスの順序は、前、次のままです。

### Web での描き方の違い

- 縦に並ぶ形は、`nav` の幅から決まるグリッド自身の列数で描きます。コンテナクエリもメディアクエリも使いません。
- パッケージのスクリプトがなくても、スタイルシートがすべての状態を描きます。このとき、押下への応え方はオーバーレイです。次の項目を先に書いた場合、描かれる順序は正しくなりますが、フォーカスの順序は次が先のままです。前の項目を先に書いてください。
- スタイルシートは、右から左のレイアウトで両方の矢印を反転します。アイコンセットがどちらのグリフも反転の対象にしていないデザインシステムでは、スクリプトが反転を取り消します。スクリプトがなければ、項目に `data-mirror="never"` を書いてください。
- ページネーションは `.tanrei-prose` の外か、`tanrei-not-prose` を付けた部分の中に置いてください。プローズは、その中のアンカーをテキストリンクとして描きます。

## ガイドライン

### 推奨

- めくる対象のコンテンツの後に、1 ページに 1 つだけ置きます。
- どのページでも両方の項目を書き、行き先のないほうは `href` を付けずにおきます。`href` のない項目は描かれません。
- 方向は、プロダクトの言葉で書きます。「前へ」と「次へ」、「新しい記事」と「古い記事」などです。

### 非推奨

- アドレスを変えずに表示だけを切り替えるボタンとして使わない。項目はリンクです。
- 隣のページを新しいタブで開かない。ひと続きのページは、その場で入れ替わっていくものです。
- 項目に独自のグリフを付けない。

## アクセシビリティ

<ComponentAccessibility name="pagination" />

### コンポーネントが担うこと

- それぞれの項目はブラウザー自身のリンクで、名前はラベル、タイトルの順です（「次へ デザイントークン」）。どちらも画面に描かれています。
- 矢印は装飾で、支援技術からは隠されます。
- 見た目の順序は、読む順序と同じです。左から右でも右から左でも、縦に並んだときも、前、次の順です。
- キーボードフォーカスのリングは、項目の周りに描きます。タイトルは折り返し、項目は読み手の文字サイズに合わせて大きくなります。

### 利用者側で行うこと

- ランドマークには、`aria-label` でプロダクトの言語の名前を付けます。ページにはほかのナビゲーションもあるので、名前で区別できるようにします。Tanrei は文言を持ちません。
- アンカーに `rel="prev"` と `rel="next"` を書きます。
- 前の項目を、次の項目より先に書きます。
