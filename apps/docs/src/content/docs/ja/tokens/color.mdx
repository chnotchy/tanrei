`tanrei.sys.color` 以下にある、すべてのシステムのカラーロールを、ライトとダークについて解決したものです。色見本は解決済みの値そのものを表示するので、どちらのテーマで読んでいても、両方のテーマを確認できます。半透明のロールは、それが想定している背景の上に描いています。ロールの意味と使い方については、[カラー](/ja/foundations/color/)を参照してください。
