## 角のスムージング

`tanrei.sys.shape.corner-smoothing` は 0 から 1 の量で、意味は Figma と同じです。0 は四分円、0.6 は Figma が「iOS の角」と呼ぶ値、1 は最もなだらかな角です。この値で半径が変わることはありません。この量の意味は Figma の作図そのものです。Compose と Flutter はその作図を描き、Web は最も近いスーパー楕円を、SwiftUI と iOS の React Native は OS の曲線を描きます（それぞれの差は[形状](/ja/foundations/shape/#角のスムージング)にあります）。同梱システムごとの値は次のとおりです。
