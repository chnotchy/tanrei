見本は、生成された CSS カスタムプロパティで組んでいます。ここに見えているものが、`@tanrei/web` が提供するものです。各ロールは、その構成要素を個別のプロパティとして公開しています。`-font-family`、`-font-size`、`-line-height`、`-font-weight`、`-letter-spacing`、`-font-weight-emphasized`、それにショートハンドの `-font` です。`h2` や `p` がどのロールにあたるのか、なぜ強調がロールではなく太さなのかといった指針は、[タイポグラフィ](/ja/foundations/typography/)を参照してください。

## 強調のステップ

強調したテキストは、ロールを、その太さにファミリーのステップを足した太さで描いたものです。ロールのファミリーは、名前の最初の区切りです。`caption`、`code`、`code-small`、`eyebrow` はラベルのステップを取ります。同梱システムごとの 4 つのステップは次のとおりです。
