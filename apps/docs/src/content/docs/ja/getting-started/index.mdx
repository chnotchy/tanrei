Tanrei は、各プラットフォームのネイティブなライブラリとして提供されるデザインシステムです。特別なランタイムやクロスプラットフォームのフレームワークを導入する必要はありません。いま開発に使っているプラットフォーム向けのパッケージを追加するだけで、ほかのすべてのプラットフォームと同じトークン、コンポーネント、アクセシビリティの振る舞いが手に入ります。

## 同じボタンを、6 通りに

すべてのコンポーネントは、プラットフォームに依存しない仕様で一度だけ定義され、各プラットフォームの流儀で実装されます。選んだタブは、サイト内のほかのページでも保持されます。

## どのプラットフォームでも得られるもの

- **トークン。** カラーロール、タイプスケール、形状、エレベーション、モーション、状態、スペーシングの値。単一の DTCG ソースから、CSS カスタムプロパティと、Swift・Kotlin・Dart・TypeScript の定数として生成されます。
- **テーマ。** ライトとダーク、それぞれに標準・中・高の 3 段階のコントラスト。既定では OS の設定に従い、アプリ全体または一部のサブツリーに対して固定することもできます。
- **コンポーネント。** 共通仕様の実装です。バリアント、状態、キーボード操作はどこでも同じです。
- **アクセシビリティの既定値。** 最小ターゲット、見えるフォーカスリング、200% の文字拡大に耐えるテキスト、動きを減らす設定への対応。これらは画面ごとに任されるのではなく、最初から組み込まれています。

## このドキュメントの読み方

- [基礎](/ja/foundations/brand/)では、考え方と規則を説明します。
- [トークンリファレンス](/ja/tokens/color/)は、すべての値をトークンファイルから直接描画して一覧にしています。
- [コンポーネント](/ja/components/)のページは、概要・仕様・ガイドライン・アクセシビリティという共通の構成です。ページ内の表はコンポーネントの仕様から生成されるため、古くなることがありません。
- [ステータス](/ja/status/)は、リポジトリから生成されます。
- [AI エージェントと Tanrei を使う](/ja/getting-started/ai-agents/)では、MCP サーバーのつなぎ方と、コーディングエージェントが Tanrei で UI を書くための規則を示します。
