`@tanrei/react` 把 `@tanrei/web` 中的每个自定义元素包装成真正的 React 组件，带有类型化的属性和事件处理函数。这些包装组件由自定义元素清单（custom elements manifest）生成，因此始终与它们包装的元素保持一致。

<ReleaseNotice platform="web" registry="npm" pkg={["@tanrei/react", "@tanrei/web"]} />

## 安装

需要 React 18 或更高版本。

### 从 npm

```sh
npm install @tanrei/react @tanrei/web
```

### 从源码

要使用 `main` 上的源码，与 [Web 包](/zh-cn/getting-started/web/)一样（Git、Node 22.22 或更高版本、pnpm 12）：在仓库的克隆中构建这两个包并打包，

```sh
git clone https://github.com/chnotchy/tanrei.git
cd tanrei
pnpm install
pnpm --filter @tanrei/web --filter @tanrei/react build
pnpm --filter @tanrei/web --filter @tanrei/react pack --pack-destination ../tanrei-packages
```

然后用一条命令把两个打包出的文件都安装到你的项目里，这样 React 包就能在旁边找到 Web 包：

```sh
npm install path/to/tanrei-packages/tanrei-web-*.tgz path/to/tanrei-packages/tanrei-react-*.tgz
```

## 使用

在组件渲染之前加载一次样式表：`tanrei.css` 把页面的基础样式、令牌和这个包的其他所有样式表放在一个文件里。要一个一个地加载，参见 [Web 指南](/zh-cn/getting-started/web/)。

```tsx
import '@tanrei/web/tanrei.css';
import '@tanrei/web/words/en';
import { Button } from '@tanrei/react';

export function Toolbar({ onDeploy }: { onDeploy: () => void }) {
  return (
    <>
      <Button variant="filled" onClick={onDeploy}>
        部署
      </Button>
      <Button variant="text" size="small" disabled>
        回滚
      </Button>
    </>
  );
}
```

属性的名称与元素的 attribute 相同（`variant`、`size`、`disabled`）。事件就是普通的 React 处理函数。元素自己的事件，与 React 自身的事件一样，用 `on` 加上驼峰式的事件名来监听（与 `onKeyDown` 同一形式）：导航抽屉发出的 `expandedchange` 用 `onExpandedChange` 监听。

`@tanrei/web/words/en` 为组件绘制或朗读的每一个标签和消息（例如必填标签、关闭按钮的名称）给出平实的英语文字；也可以不用它，而用 `@tanrei/react` 的 `setWords()` 给出你自己的文字。参见[文字](/zh-cn/foundations/words/)。

## 每个设计系统一个入口

这个包为 Tanrei 自带的每个设计系统各提供一个入口，这样编辑器提示的、类型检查接受的，只有你的系统所拥有的内容：

| 入口 | 导出的内容 |
|---|---|
| `@tanrei/react` | 默认系统 Tanrei 的组件。位于 m3-like 层的 FAB 菜单，以及 Tanrei 不包含的分段按钮，都不在其中；Tanrei 不包含的变体也不是该属性的取值：`<TextField variant="outlined">` 无法通过类型检查 |
| `@tanrei/react/m3-like`、`@tanrei/react/m3-expressive-like`、`@tanrei/react/cupertino` | 该预设的组件及其变体 |
| `@tanrei/react/advanced` | 进阶组件，即用于构成其他组件的部件：`TextInput`、`ModalLayer`、`Combobox` 等。产品通常写的是由它们构成的组件：`TextField`、`Dialog`、`ComboboxField` |
| `@tanrei/react/all` | 所有组件，不论属于哪个系统：用于你自己的设计系统，以及构建设计系统 |

```tsx
import '@tanrei/web/tokens.css';
import '@tanrei/web/systems/m3-like.css';
import { FabMenu, FabMenuItem, TextField } from '@tanrei/react/m3-like';
```

同一个组件在每个入口中都是同一个，因此打包工具仍然只保留你导入的部分。每个入口也都导出 `setWords`、`missingWords` 和 `TanreiEvent` 类型。这些入口由每个系统的组件清单 `@tanrei/web/systems/<id>.components.json` 生成，清单中写明了每个组件的入口（`react.import`）；由 `tanrei build` 写出的你自己系统的清单，写的是 `@tanrei/react/all`。

## 服务端渲染

在没有 `document` 的服务端，组件会渲染出元素的标签，并把元素从属性读取的每个 prop 以该属性的名称写成属性。首次返回的 HTML 中就已经有标签文字、值和状态：

```tsx
<TextField label="电子邮箱" value="ada@example.com" required maxLength={80} readOnly={false} />
// <tanrei-text-field label="电子邮箱" value="ada@example.com" required="" maxlength="80"></tanrei-text-field>
```

处于默认值的 prop 不会写出任何内容，因此 `false` 永远不会被写成“存在”。默认开启的布尔值被关闭时，会写出元素读作“关闭”的属性：`<CopyButton iconOnly={false} />` 写出 `icon-only="false"`，`<BottomSheet handle={false} />` 写出 `no-handle`。处理函数、对象和数组在浏览器中、组件挂载时才设置。服务端不渲染影子根：元素在其定义加载后自行绘制，React 对该标签进行水合时不会出现不匹配。

### Next.js（App Router）

组件使用 ref 和布局副作用，因此要在客户端组件中使用。请在标有 `'use client'` 的模块中导入它们；服务端组件可以渲染这个模块，首次加载时 Next.js 仍会在服务端渲染它。

```tsx
// app/sign-up.tsx
'use client';

import '@tanrei/web/words/en';
import { Button, TextField } from '@tanrei/react';

export function SignUp() {
  return (
    <form action="/sign-up" method="post">
      <TextField name="email" type="email" label="电子邮箱" required />
      <Button type="submit">注册</Button>
    </form>
  );
}
```

```tsx
// app/layout.tsx
import '@tanrei/web/tanrei.css';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="zh-CN">
      <body>{children}</body>
    </html>
  );
}
```

```tsx
// app/page.tsx (服务端组件)
import { SignUp } from './sign-up';

export default function Page() {
  return <SignUp />;
}
```

不支持 Lit 的服务端渲染器（`@lit-labs/ssr-react`、`@lit-labs/nextjs`）：它会在服务端渲染影子根，而许多元素在渲染时要读取自己的子元素和文档，这个渲染器并不提供这些，所以会失败。请不要安装它；服务端发送的就是上面的属性。
