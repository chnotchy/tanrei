## 许可证

Tanrei 以 **{config.license}** 许可证发布。在遵守该许可证条款的前提下，你可以在商业和非商业产品中使用它、修改它并再分发。许可证全文见仓库的 `LICENSE` 文件，必需的声明见 `NOTICE`。

## 第三方成果

| 成果 | 在 Tanrei 中的用途 | 许可证 |
| --- | --- | --- |
| material-color-utilities | 构建时在 HCT 色彩空间中生成色调调色板和配色方案 | Apache-2.0 |
| Inter | 拉丁文字的默认字体，由字阶按名称引用 | SIL Open Font License 1.1 |
| Noto Sans JP、Noto Sans | 日文及其他文字的默认字体 | SIL Open Font License 1.1 |
| Roboto Mono | 默认的等宽字体 | Apache-2.0 |
| Material Symbols (Rounded) | 默认的图标字体，由 `ref.typeface.icon` 按名称引用 | Apache-2.0 |
| Material Symbols 的矢量可绘制资源（vector drawable） | 从右到左的布局中需要镜像的字形名称列表的来源（`tokens/icon-sets/`，仅取名称） | Apache-2.0 |
| material-web 和 androidx.compose.material3 的令牌 | 预设 `m3-like` 测量保真度时所对照的参考值（`tokens/fidelity/`，仅取值） | Apache-2.0 |
| Lit | Web Components 的基础库 | BSD-3-Clause |
| Astro 和 Starlight | 本文档站点 | MIT |
