## 圆角平滑

`tanrei.sys.shape.corner-smoothing` 是一个 0 到 1 之间的量，含义与 Figma 相同：0 是四分之一圆，0.6 是 Figma 所说的 iOS 圆角，1 是最平缓的过渡。半径不随它改变。这个量的含义就是 Figma 的构造法；Compose 和 Flutter 按这种构造绘制，Web 绘制最接近的超椭圆，SwiftUI 和 iOS 上的 React Native 绘制操作系统自己的曲线（各自的差距见[形状](/zh-cn/foundations/shape/#圆角平滑)）。各内置系统的取值：
