## 指南

### 何时使用

进度指示器用于耗时长到会被注意到的任务：上传、导入、部署、耗时较长的保存。只要你能测量进度，哪怕只是粗略地测量，就显示任务已经进行到哪里；面对一个会前进的进度条，人们等得更有耐心。暂时无法测量时，把它显示为不确定的形式，一旦有了数值就切换为显示数值。

对于时长无法测量的短暂等待，例如列表正在获取下一页，请改用[加载指示器](/zh-cn/components/loading-indicator/)。它没有轨道，因为它从不承诺一个数值。

### 如何选择变体

| 变体 | 用途 |
| --- | --- |
| 线性 | 属于某个页面或某个区域的任务：页面顶部、卡片内部、上传列表中某个文件的下方。进度条会占满布局分配给它的宽度。 |
| 环形 | 空间紧凑的地方，以及文本旁边的进度：按钮里、列表行里、小面板里。圆环的尺寸是固定的。 |

### 如何选择尺寸

| 尺寸 | 默认系统中的进度条粗细 / 圆环尺寸 | 用途 |
| --- | --- | --- |
| Small | 2 / 16 | 紧凑的行、控件内部、小号文本旁边。 |
| Medium | 4 / 24 | 大多数地方。这是默认尺寸。 |
| Large | 8 / 40 | 整个视图所围绕的那一项任务，或者等待内容的空白区域。 |

### 分隔线还是间隙

确定形式的指示器与轨道的其余部分有两种区分方式。使用 `divider` 时，指示器直接画在轨道上，两者之间没有空隙。使用 `gap` 时，指示器之后会留出一小段空白——圆环上是在圆弧的两端。不确定形式的指示器在两种方式下外观相同。进度条是否用一个圆点标出轨道的终点是另一项选择，由停止指示器的尺寸决定：为它设定了尺寸的设计系统在两种分隔方式下都会画出圆点，默认系统则不画。

设计系统为所有具有这项选择的组件统一选择一次，默认系统选择的是 divider。让 `separation` 保持 `auto` 就会遵循这一选择，这样指示器与周围的按钮组和菜单保持一致。只有当某一个指示器有理由与众不同时，才在它上面设置 `divider` 或 `gap`。

### 推荐

- 给它一个说明正在进行什么的标签：写“正在上传 report.pdf”，不写“进度”。如果它旁边显示了说明文字，请使用同样的措辞。
- 百分比读起来不自然时，使用数值文本：“第 3 个文件，共 10 个”“第 2 步，共 4 步”。
- 任务结束时，用文字告诉用户：一条说明任务已完成的消息，或者说明出了什么问题以及接下来该怎么做。

### 避免

- 不要用颜色来报告失败。对看不到颜色的人来说，红色的进度条什么也没说；应当停止指示器，并在它旁边显示一条消息。
- 不要把它当作显示某个水平的量表，例如已用存储空间或密码强度。那是[计量条](/zh-cn/components/meter/)（meter），是另一个组件。
- 不要让数值倒退，也不要在任务完成之前跳到终点。进度条是对剩余等待时间的承诺。
- 不要为同一项任务显示多个指示器。为整体显示一个，或者为用户关心的每一项各显示一个。

## 无障碍

### 组件负责的部分

- 它提供进度条角色，以标签作为名称。确定形式下，它提供范围、当前值（限制在范围之内），以及数值文本（如果有的话）；不确定形式下，它不提供数值，而提供平台的“忙碌”状态。Flutter 目前还没有进度条角色和忙碌状态，所以在那里它提供标签和数值。
- 它从不可聚焦，也不会朗读自己的变化。用户到达它时，辅助技术会读出当前值。
- 用户要求减弱动态效果时，数值的变化会立即显示；不确定的形式停止运动，改为轻缓地改变不透明度，每秒至多一次。
- 在看不见它的时候，它的循环动画会停止——在所有平台上，应用处于后台时都是如此；在平台能够判断的情况下，它被滚出视野或位于隐藏的屏幕上时也是如此——看得见时再恢复。
- 空的标签、超出范围的数值和未知的 `separation` 会在调试构建中报告。

### 需要你做的事

- 任务的结束要由你自己来朗读：在实时区域（live region）里放一条消息，或者把焦点移到结果上。指示器不会说明任务已经完成或已经失败。
- 如果你更改了颜色，请让指示器的颜色相对于轨道和它背后的表面至少保持 3:1 的对比度，使用分隔线和使用间隙时都是如此。数值是从指示器与轨道相接的位置读出来的。
- 在最高容器色调的表面上（例如填充卡片），轨道几乎是同一色调，很难看清。指示器放在这样的表面上时，请在图层中把 `comp.progress-indicator.track.color` 指向更强的角色。指示器所显示的内容仍然从它与轨道相接的位置读出。
- 如果任务会阻塞页面的某个区域，请在任务运行期间把这个区域标记为忙碌（在 Web 上是 `aria-busy`）。
