弹出框用于用户要在打开它的控件旁边处理的内容：几项设置、一个简短的表单、一个分享面板、一条需要链接或按钮的说明。它周围的页面其余部分仍然可以使用。在 compact 窗口中，它改为以底部面板的外观出现在窗口底部；在 compact 窗口中，Tanrei 的每个弹出框和对话框都是这样。

### 用法

控件是你自己的。在 Web 上，你用 `anchor` 指明它：弹出框贴着哪个元素放置，就写哪个元素的 id。这个元素同时也是打开弹出框的控件（opener）：弹出框会告诉辅助技术，这个控件会打开一个对话框，以及这个对话框当前是否打开；关闭时也把焦点交还给它。如果表面以一个输入框为锚点，而打开它的是输入框里的一个按钮，就用 `opener` 指明这个按钮。

弹出框与菜单一样，是受控组件。它用 `toggle` 请求打开或关闭，`detail.open` 是它请求的值，由你把 `open` 设为这个值。默认情况下，按下打开它的控件会请求打开，再按一次会请求关闭，所以你不需要在这个控件上写处理函数。其他情况下，它用 `close` 请求关闭，由你把 `open` 设回 false。`close` 带有原因：`escape`、`outside`、`focus-out`、`close`（它的关闭按钮）或 `anchor-hidden`。在 compact 窗口中作为面板显示时，按下遮罩会发送 `outside`，而不会发送 `focus-out` 或 `anchor-hidden`。操作按钮从不关闭弹出框，关闭它的是你的处理函数。

请给它一个名称：画出标题时用 `headline`，不画标题时用 `label`。

### 触发方式

`trigger` 指定什么会打开弹出框：`press`、`hover` 和 `focus` 中的一个或多个，可以任意组合。在 Web 上，这个属性用空格分隔各个值，例如 `trigger="hover focus"`。

| 触发方式 | 何时打开弹出框 | 焦点去哪里 |
| --- | --- | --- |
| `press`（默认） | 按下打开它的控件，或在这个控件上按 Enter 或 Space。再按一次会请求关闭 | 进入弹出框 |
| `hover` | 鼠标、触控板或可悬停的笔在锚点上停留 `showDelay` 这么久。触摸永远不会打开它 | 不移动，留在原处 |
| `focus` | 键盘焦点在锚点上停留 `showDelay` 这么久。按下或点按带来的焦点不算 | 不移动，留在锚点上；下一次 Tab 进入弹出框 |

`toggle` 用 `detail.reason` 说明是哪种触发方式。通过悬停或聚焦打开的弹出框：

- 打开前会等待，这样指针从锚点上经过，或用 Tab 依次经过一排锚点时，都不会打开。不写 `showDelay` 时，使用 `comp.popover.motion.show-delay`（默认系统中为 700 ms）。
- 只要指针在锚点上、在锚点与弹出框之间的空隙上，或在弹出框上，或者焦点在弹出框里，它就保持打开。触发方式包含 `focus` 时，锚点上的键盘焦点也会让它保持打开。无论 `hideDelay` 是多少，指针都能穿过空隙。
- 以上都不成立的状态持续 `hideDelay` 之后，它用 `toggle` 请求关闭，原因是 `leave`。不写 `hideDelay` 时，使用 `comp.popover.motion.hide-delay`（默认系统中为 300 ms）。只要有一项成立，它就不会因计时而关闭。
- 无论焦点在哪里，按 Esc 都会关闭它，焦点留在原处。按 Esc 关闭后，要等指针或焦点离开锚点再回来，它才会再次打开。
- 在 compact 窗口中也显示在锚点旁边，因为面板会在用户只是指向锚点时夺走焦点。
- 以与其他弹出框相同的动效出现。

触发方式包含 `press` 时，在通过悬停打开的弹出框上按下打开它的控件，弹出框会保持打开，就像是按下打开的一样：焦点移入其中，指针离开也不再关闭它。不包含 `press` 时，这个控件执行它自己的动作，例如链接的跳转，而且它不会声明自己会打开对话框。

这些等待是时间，不是动效：在减少动态效果时也保持不变。

SwiftUI、Compose、Flutter 和 React Native 尚在计划中：本页开头各平台旁边的名称是规格为它们定下的，这些平台目前还没有提供任何实现。

### 位置

`placement` 指明弹出框位于锚点的哪一侧，以及沿这一侧怎样对齐。它的十三个值就是工具提示的那十三个，含义也相同。

| 值 | 位置 |
| --- | --- |
| `bottom-start`（默认）、`bottom`、`bottom-end` | 锚点下方：起始边对齐、居中，或末尾边对齐 |
| `top-start`、`top`、`top-end` | 锚点上方，同样的三种对齐方式 |
| `start`、`start-top`、`start-bottom` | 锚点的起始侧：居中、顶边对齐，或底边对齐 |
| `end`、`end-top`、`end-bottom` | 锚点的末尾侧，同样的三种对齐方式 |
| `auto` | 按下方、上方、末尾侧、起始侧的顺序，取第一个有空间的 |

起始和末尾随布局方向而变。`offset` 是到锚点的距离，以平台的布局单位计；不设置时采用 `comp.popover.offset`。`crossOffset` 让弹出框沿它所在的一侧移动，但绝不会移出锚点的这一侧。

弹出框与窗口边缘保持 `comp.popover.window-margin` 的距离，为此依次采取以下步骤：

1. 首选的一侧没有空间时，它翻转到相对的一侧，并保持原来的对齐方式。
2. 两侧都没有空间时，它取空间较大的一侧，并且尺寸以这块空间为限。这时它的内容可以滚动。
3. 它沿所在的一侧平移，直到满足边距的要求。
4. 窗口比它的最小尺寸还小时，它宁可盖住锚点，也不超出窗口。

锚点移动时，它跟随锚点；只要所在的一侧还有空间，它就留在这一侧。锚点完全看不见时，它触发 `close`，原因是 `anchor-hidden`。

### 尺寸

弹出框与它的内容一样宽，介于 `comp.popover.container.min-width`（160）和 `container.max-width`（400）之间。设置 `width="anchor"` 后，它与锚点一样宽，适合从输入框下方展开的表面。它绝不会比窗口减去边距后的宽度更宽。

它与各个部件加起来一样高，上限是 `container.max-height`（480）和所在一侧的可用空间。超过这个高度时，内容在页眉和操作之间滚动，页眉和操作留在原位。只要内容在滚动，页眉下方和操作上方就各有一道分隔线。把 `dividerVisibility` 设为 `scroll`（在 Web 上是 `divider-visibility`），页眉下方的分隔线就只在内容被滚动之后出现，操作上方的只在下面还有更多内容时出现；`cupertino` 和 `m3-like` 为所有弹出框选择了这种方式。SwiftUI、Compose、Flutter 和 React Native 在跟上之前都这样绘制。

对于自带内边距或一直延伸到边缘的内容，例如列表，请把 `inset` 设为 false（在 Web 上是 `no-inset`）。

### 部件

| 部件 | 它是什么 |
| --- | --- |
| 页眉 | 标题，以及 `closable` 为 true 时的关闭按钮。内容滚动时它留在原位 |
| 内容 | 默认插槽。可以是任何东西，包括链接、输入框和其他控件 |
| 操作 | `actions` 插槽里的 Tanrei 按钮；属于确认或取消性质的，各自标为 `confirming` 或 `dismissive`。它们按按钮组的方式摆放，标签放不下时叠成一列 |
| 箭头 | 一个可选的三角形，指向锚点。`arrow` 为单个弹出框打开它；`comp.popover.arrow.visible` 为整个设计系统打开它 |

没有 `variant` 的操作采用 `comp.popover.actions.variant`（在默认系统中是 tonal）。关闭按钮是一个纯图标的 small 按钮，变体取自 `comp.popover.close-button.variant`：在默认系统中是 tonal，与 Tanrei 的每个关闭按钮一样，在任何内容上都能被看作一个控件。m3-like 和 cupertino 预设保留各自不带底色的字形（text）。

### 动效

弹出框的出现方式与 Tanrei 中所有出现的界面相同：从朝向锚点的那条边的中点淡入，同时略微变大（默认系统中从 96 % 开始）；关闭时沿原路返回，稍快一些。被打断的动效会从当前位置掉头。在减弱动态效果时，它只淡入淡出。在 m3-like 预设下，它改为像 Material 的菜单那样从那条边展开。在页面标记中写有 open 的弹出框从第一帧起就在那里，不带动效。

### 在 compact 窗口中

在窄于 `comp.popover.compact.window-width`（默认系统中为 600）的窗口中，弹出框采用底部面板的外观。这是 Tanrei 对 compact 窗口中每个弹出框和每个对话框的规则。你打开的仍是同一个弹出框，props 和事件也相同；改变的只是它的绘制方式。

- 它贴在窗口的底边，宽度与窗口相同，最宽到 `comp.bottom-sheet.container.max-width`，使用底部面板的颜色和高度（elevation）。上方的角取 `comp.bottom-sheet.container.shape`，下方的角是直角。屏幕键盘出现时，它位于键盘之上。
- 它的高度随内容而定，但不会高于窗口减去顶部的 `comp.bottom-sheet.container.margin-block-start`。超出部分的内容在标题区和操作之间滚动。
- 它没有箭头，也没有拖动手柄，不跟随拖动。`placement`、`offset`、`crossOffset` 和 `width` 都不适用。
- 它是模态的：底部面板的遮罩让页面变暗，它后面的一切都变为惰性，焦点留在它里面。Esc、返回、按下遮罩和关闭按钮都会关闭它。
- 它以底部面板的动效从底边升起，关闭时再滑下去。在减弱动态效果时，它在原地淡入淡出。
- 弹出框打开时如果窗口宽度越过这个值，它会立即改变形态，没有动效，焦点保持不变。

把 `compactPresentation` 设为 `own`（Web 上为 `compact-presentation="own"`），可以让某个弹出框在任何窗口中都留在锚点旁边，用于必须紧挨着所属内容的表面。`initialFocus="anchor"` 的弹出框总是留在锚点旁边，因为用户正在输入的输入框必须保持可用。从不想要面板的设计系统把 `comp.popover.compact.window-width` 设为 0。

这里说的弹出框不包括菜单：菜单、选择器或组合框的列表以及按钮的菜单，在任何窗口中都留在它们的控件旁边。

### Web 上绘制方式的不同之处

- 弹出框是顶层（top layer）中的 `popover="manual"` 元素。位于模态 `<dialog>` 之内时，它必须是这个对话框的后代，才能在那里操作。
- 在 compact 窗口中，面板是用 `showModal()` 打开的原生 `<dialog>`，遮罩就是它的 `::backdrop`。
- 在外部按下会关闭弹出框，这次按下也会传到它下方的元素。
- Web 没有自己的返回手势，所以 `close` 绝不会带有原因 `back`。
- `anchorElement` 和 `openerElement` 是属性（property），用于 id 够不着的元素，例如位于另一个 shadow root 里的元素。
- `arrow` 可以是未设置、true 或 false：这个属性（attribute）可以不写、写成 `arrow`，或写成 `arrow="false"`。
- `trigger` 是列表属性（property），它的属性（attribute）用空格分隔各个值。`showDelay` 和 `hideDelay` 对应 `show-delay` 和 `hide-delay` 属性，单位为毫秒。
- `toggle` 是带有 `detail.open` 和 `detail.reason` 的 `CustomEvent`。在标记中，可以用 `ontoggle="this.open = event.detail.open"` 响应它。
- 悬停由 `pointerType` 为 `mouse` 或 `pen` 的指针判断，键盘焦点由匹配 `:focus-visible` 的焦点判断。
- 用 `autofocus` 标记打开时取得焦点的元素。
- 在强制颜色模式下，容器和它的箭头带有一道文本颜色的边线。

## 指南

### 工具提示、弹出框、菜单还是对话框

| 方面 | 工具提示 | 弹出框 | 菜单 | 对话框 |
| --- | --- | --- | --- | --- |
| 怎样打开 | 悬停、键盘聚焦、长按 | 按下打开它的控件；`trigger` 指定时，也可以是悬停或键盘聚焦 | 按下它的锚点 | 由产品打开 |
| 里面是什么 | 对锚点的描述 | 供用户操作的内容 | 只有菜单项 | 一项决定 |
| 是否取得焦点 | 从不 | 按下打开时取得，并且交还 | 是，并且交还 | 是，并且留住 |
| 是否阻挡页面 | 否 | 否（在 compact 窗口中作为面板时为是） | 否 | 是 |

1. 如果它只是说明控件是什么，里面没有任何可以按下的东西，它就是工具提示。
2. 如果它是一列命令或选项，它就是菜单。
3. 如果用户不作出回应就无法继续，它就是对话框。
4. 否则它就是弹出框。

### 切换提示

切换提示（toggletip）是放在一个小信息按钮后面的简短说明，按钮就在它所解释的内容旁边。它不是一个独立的组件，而是一个打开弹出框的按钮。在工具提示不够用的地方使用它，比如说明里有链接，或者必须能通过触摸打开，并把内容控制在一两句话。

- **按钮。** 一个纯图标按钮，`variant="text"`、`size="small"`，它的 `label` 说明这条说明是关于什么的（“关于存储空间”），而不是“信息”。按一下打开弹出框，再按一下关闭；弹出框把这个按钮指定为它的 `anchor`。
- **弹出框。** 用 `label` 为它命名；要绘制标题时用 `headline`。和所有弹出框一样，它打开时获得焦点，关闭时把焦点交还给按钮，按 Esc 或在外部按下也会关闭它。
- **不要用它代替页面。** 用户继续之前必须读到的内容，应写在字段的辅助文字或页面本身里，不需要谁去询问。

### 推荐

- 默认通过按下某个控件来打开它。再次按下这个控件时，弹出框会请求关闭。
- 对链接目标的预览（例如一个人或一份文档）使用 `trigger="hover focus"`，并确保用户顺着链接也能看到同样的信息。
- 通过悬停打开的弹出框里有可操作的内容时，在触发方式中加上 `press`，让使用键盘或触摸的用户能有意地打开它并进入其中。
- 内容要短。只做一件事，最多几个输入框。
- 如果弹出框大到会盖住用户原本要在外部按下的地方，就加上 `closable`；在没有 Esc 的触摸设备上也要加。
- 位于用户正在输入的输入框下方的表面，使用 `width="anchor"` 和 `initialFocus="anchor"`。
- 只有在 compact 窗口中也必须留在所属内容旁边的弹出框（例如紧挨着它所解释的词的注释），才把 `compactPresentation` 设为 `own`。
- 操作的标签要短。比弹出框还宽的标签不会换行。

### 避免

- 不要把用户需要的信息只放在通过悬停打开的弹出框里。触摸设备上没有悬停，请提供另一条途径获得同样的信息：链接的目标，或在触发方式中加上 `press`。
- 不要为了让悬停弹出框显得快而缩短 `showDelay`。弹出框比工具提示大，指针每次经过都会盖住页面。
- 不要把在外部误按一下就会丢失的内容放进弹出框。长表单应该放在对话框或面板里。
- 不要在弹出框里嵌套一层以上的弹出框。每多一层，就要多按一次 Esc。
- 用户必须先作出回应才能继续的内容，不要用弹出框。那是对话框。

## 无障碍

<ComponentAccessibility name="popover" />

### 组件负责的部分

- 容器是一个非模态的对话框，以 `headline` 或 `label` 命名。它之外的任何东西都不会被隐藏，也不会变为惰性（inert）。
- 在 compact 窗口中以面板形式显示时，容器是一个模态对话框：它之外的一切都变为惰性，Tab 和 Shift+Tab 在它里面循环。关闭时焦点回到打开它的控件。
- 触发方式包含 `press` 时，打开它的控件会暴露两点：它会打开一个对话框，以及这个对话框当前是否打开。只通过悬停或聚焦打开它的锚点，这两点都不暴露。控件自己的名称和角色不变。
- 通过悬停或聚焦打开的弹出框符合 WCAG 1.4.13（悬停或聚焦时显示的内容）：不移动指针和焦点就能用 Esc 关闭它，指针可以穿过空隙移到它上面，并且在指针和焦点离开之前它一直显示。
- 打开时，焦点移到你标记的元素上，否则移到容器，这样弹出框的名称会最先被读到。只有从键盘打开弹出框时，容器上才显示焦点指示。
- 无论弹出框在文档中的什么位置，它在 Tab 顺序中都紧跟在打开它的控件之后。在它的最后一个元素上按 Tab，焦点会移到这个控件之后的内容上，弹出框随之关闭。焦点从不被留在里面。
- Esc 只关闭最上面的浮层，并且不再向外传递：包含弹出框的对话框保持打开。
- 关闭时，如果焦点原本在弹出框之内，就把焦点交还给打开它的控件。如果用户已经把焦点移到了别处，焦点就留在那里。
- 从弹出框内部打开的浮层，例如菜单或工具提示，属于这个弹出框：在其中按下或聚焦不会关闭弹出框。
- 文本放大到 200% 时，弹出框里的文本换行，弹出框增大到上限，然后滚动。在 compact 窗口中，它是横跨窗口宽度的面板。保持自身形态的弹出框，在宽 320 的窗口里，宽度是窗口宽度减去边距。

### 需要你做的事

- 给弹出框一个 `headline` 或 `label`；设置了 `closable` 时，再给一个 `closeLabel`。
- 把 `open` 设为 `toggle` 请求的值，并在 `close` 时把它设为 false。
- 只使用 `hover` 时，确保弹出框显示的内容也能通过其他途径获得，因为使用触摸的用户永远看不到它。
- 在 Web 上，请尽量把弹出框元素放在文档中紧跟在打开它的控件之后的位置，让屏幕阅读器的阅读顺序与 Tab 顺序一致。
- 简短表单的第一个输入框，请标记为初始焦点。只有文本的弹出框不要加标记。
