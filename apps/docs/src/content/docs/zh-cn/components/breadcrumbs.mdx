面包屑显示的是页面在层级结构中的位置，而不是用户来到这里所走的路。在页面位于其他页面之内、深度达到三级或更多的地方使用它。

### 用法

在 Web 上，面包屑是包在你自己的锚元素外面的一个元素。锚元素留在文档里，所以在任何脚本运行之前它们就已经是链接，爬虫、处理页面上锚元素的路由以及路由自带的链接组件都能找到它们。

有目的地的层级是 `<a href>`。没有目的地的层级是 `<span>`：当前页面，或者没有自己页面的层级。

SwiftUI、Compose、Flutter 和 React Native 尚在计划中：本页开头各平台旁边的名称是规格为它们定下的，这些平台目前还没有提供任何实现。

| --- | --- |

- 在默认系统中，**通向某个地方的层级带下划线**。在那里，表明某一级是链接的是下划线，而不是颜色，与句子里的链接一样。没有目的地的层级是次要文本。当前页面的字重更重，用文本颜色，从不带下划线。
- **什么时候画下划线是一项选择。** `underline="hover"` 只在某一级处于悬停、键盘聚焦或按下状态时画它。`underline="never"` 完全不画。不写这个属性时，面包屑跟随 `comp.breadcrumbs.underline.visibility`，而它又跟随设计系统为所有文本链接所做的选择。只有在链接颜色与文本颜色区分得开的地方，才选择 `hover` 或 `never`。强制颜色模式下总是会画出这条线。
- **当前页面是文本。** 指向用户所在页面的链接哪里也去不了，还会给每个页面多加一个 Tab 停靠点。只有当页面的各个视图在同一个地址下切换时，才给它 `href`。这时它是一个外观相同的链接。如果页面的标题紧接在面包屑下方，可以不写当前页面。
- **分隔符是组件的**：相邻两级之间是 `chevron_right`。绝不要把分隔符写进标签里。
- **长的面包屑会折叠中间的部分。** 在 `collapse` 下，面包屑保持在一行里。各级从紧挨第一级的那一级开始收到溢出按钮后面，宽度要求收多少就收多少，然后才是第一级。最后一级永远不会被收走。只有当一行里只剩溢出按钮和它、却仍然放不下时，它的标签才会被截断。
- **溢出按钮打开一个菜单**，里面是被收走的各级，按面包屑中的顺序排列。有目的地的层级在那里同样是链接。菜单的行从不带下划线。
- **`wrap` 保留每一级**，并让面包屑排成多行。任何一行都不会以分隔符开头，也没有标签会被截断。
- **它按自己的宽度折叠**，而不是按窗口的宽度；它的宽度、某个标签或文本大小改变时，它会重新决定。
- **从右到左时**，面包屑从右侧排起，分隔符指向左侧。从左到右书写的名称保持它自己的顺序。

### Web 上绘制方式的不同之处

- 在元素定义之前，以及禁用脚本时，样式表画出的是换行的形态：每一级，连同它们的分隔符。宽度放得下的面包屑在元素定义时不会发生位移。地标、列表和折叠则随元素一起到来。
- 在菜单里选择一个层级，就是在你自己的锚元素上的一次 `click`，随后浏览器跟随这个锚元素，除非你取消了这次 click。路由的链接组件在那里接管导航的方式，与在面包屑里完全一样。
- 换行的标签是一个框：焦点环画在这个框的周围，而不是画在它在每一行上的那一部分周围。
- 带字形的层级按布局的方向排列，所以在从右到左的面包屑中，带字形的从左到右的标签不会采用它自己的方向。
- 层级的字形和样式表画出的分隔符需要 `icons.css`。没有它时，它们的位置会留着，里面什么也不画。
- 请把面包屑放在 `.tanrei-prose` 之外，或者给它标上 `tanrei-not-prose`：长文排版会把自己的锚元素画成文本链接。

## 指南

### 推荐

- 把面包屑放在页面标题的上方，每个页面一个。
- 从层级结构的顶层到当前页面依次列出各级，使用页面自己的名称。
- 没有自己页面的层级，让它保持为文本。

### 避免

- 不要用面包屑来显示用户走过的步骤。它显示的是页面在哪里。
- 除了最后一级之外，不要把任何一级标记为当前页面。
- 不要在新标签页中打开某一级。同一个层级结构里的各级，替换的是用户所在的页面。
- 不要手工隐藏层级。在每一级都必须始终显示的地方，请使用 `overflow="wrap"`。

## 无障碍

<ComponentAccessibility name="breadcrumbs" />

### 组件负责的部分

- 面包屑是一个导航地标，里面是一个有序列表。每一级是一个列表项，每个链接都是浏览器自己的链接。
- 当前页面带有你写下的 `aria-current="page"`。它的名称里不会添加任何东西。
- 分隔符和字形对辅助技术隐藏。
- 被收走的层级不会被朗读，也不在焦点顺序里。它在菜单里，按一下就能到，它的锚元素也仍在文档里。
- 溢出按钮会说明它会打开一个菜单，以及菜单是否打开。
- 链接的点击区域达到最小目标，而不改变画出来的样子。
- 获得焦点的层级被收走时，焦点移到溢出按钮上。溢出按钮消失时，焦点移到重新出现的第一个层级上。

### 需要你做的事

- 用 `label` 为这个地标命名，使用你的产品的语言。页面上还有别的导航，这个名称把它与它们区分开。Tanrei 不自带任何文字。
- `overflow` 为 `collapse` 时，用 `overflow-label` 为溢出按钮命名，或者用 `setWords({ breadcrumbsOverflowLabel })` 为整个产品只给一次。
- 用 `aria-current="page"` 标记当前页面，并且只标在最后一级上。
- 给只显示为一个字形的层级写上文本。文本就是它的名称。
