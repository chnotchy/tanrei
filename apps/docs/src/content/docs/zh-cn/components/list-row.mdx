列表行是大多数列表由之构成的那种行：一个名称、关于它的一两行文字，以及放在它前面和后面的内容。[列表](/zh-cn/components/list/)是一个容器，负责排列各项并把它们变成操作、链接或选项；列表行是某一项显示的内容。把它放在列表项中，或者在只需要一行的地方单独使用。

行只绘制文本和字形。它没有自己的填充、边框、悬停和焦点，本身也从不可按：这由它所在的列表项决定。

在 Web 上它是 `<tanrei-list-row>`。其他平台尚未实现。

### 各种列表项中的行

行从它所在的列表项得知这一项是什么，并据此绘制自己：

- **静态项，或单独使用的行。** 行绘制自己的内边距和自己的颜色。起始或末尾插槽中的控件保留自己的焦点和按下。
- **交互项、链接项或选项。** 列表项为内容加内边距，所以行不绘制自己的内边距，只保持自己的高度：静态项和可按的项混排的一列仍保持同一高度。列表项以行的标题命名，并以行的其他文本描述。被选中的选项会以其选中时的内容颜色绘制行的文本和字形。
- **可重新排序的列表。** 列表的手柄位于该项起始处、行的前面，取代行起始侧的内边距。
- **有字形和没有字形的行。** 当列表的 `iconSpace` 要求时（默认情况下，即列表中另有一行画了前置字形时），没有前置部分的行会为字形保留空间并留空，使其标题与其他行的标题从同一位置开始。单独使用的行不保留。
- **水平列表或换行的列表。** 排成一行时，行的宽度等于其各部分的宽度，从不截断；换行时，行不会比列表更宽，必要时文本会被截断。

请把行作为列表项的直接子元素。在列表项中被其他元素包裹的行得不到任何信息，会像单独使用时那样绘制。

## 指南

### 何时使用

当列表中的人、地点、设置、消息或文件都显示同样的几个部分时，为每一项使用列表行。如果各项是图块、卡片或图片，就在列表项中放入你自己的内容；正在发送的文件使用[文件项](/zh-cn/components/file-item/)。

### 组成部分

| 部分 | 用途 |
| --- | --- |
| 标题 | 该项的名称。辅助技术、可重新排序列表的手柄和输入查找都用它来称呼这一列表项。 |
| 上标文本 | 名称上方的简短类别、来源或时间。 |
| 辅助文本 | 该项的内容、状态、消息的开头：一行，或用 `supportingLines` 设为两行。 |
| 前置字形或插槽 | 该项是哪一类东西（`leadingIcon`），或它的头像或图片（`leading` 插槽）。 |
| 后置文本 | 一个简短的值：数量、大小、时间、设置的当前值。 |
| 末尾插槽 | 徽章；在静态行中可以是开关、复选框或纯图标按钮。 |
| 后置字形 | 表示该行会打开某物的 V 形箭头，或一个状态。 |

标题、上标文本和辅助文本放不下时会以省略号截断；被截断的标题和辅助文本在悬停和键盘聚焦时由工具提示显示全文。后置文本从不超过行宽的一半。

### 密度

在默认系统中，`regular` 行在一行、两行、三行时分别高 56、72、88，适用于既用触摸又用指针的产品。`compact` 行（40、56、72）适用于用指针操作的工具。操作、链接或选项无论密度如何，都不会低于列表自己的最小高度和触摸目标。

### 推荐

- 为每一行提供标题。上标文本保持为简短的类别，后置文本保持为简短的值。
- 在列表中，没有字形可显示的行就不要放字形：列表会保留它的空间，标题仍然对齐。图片的空间不会被保留，所以同一列中的行要么都有图片，要么都没有。
- 会打开某物的行，应作为交互项或链接项的内容。

### 避免

- 不要在作为交互项、链接项或选项内容的行中放控件。这样的项是一个元素，辅助技术无法到达其中的控件。这样的行应保持静态。
- 不要自己给行加点击处理来让它可按。请使用带有焦点、状态和最小目标的列表项。
- 不要只靠后置字形来说明行的作用。说明它的是标题和列表项的角色。

## 无障碍

<ComponentAccessibility name="list-row" />

### 组件负责的部分

- 行的文本按绘制顺序作为文本朗读：上标文本、标题、辅助文本、后置文本。字形被隐藏。
- 包含该行的列表项在没有标签时以行的标题命名；操作、链接或选项以行的上标文本、辅助文本和后置文本描述。
- 被截断的文本对辅助技术始终是完整的。工具提示对辅助技术隐藏，在悬停和列表项获得键盘焦点时打开，指针停在其上时保持显示，按 Escape 关闭。
- 在从右到左的布局中，行会镜像，每段文本保持自己的方向。
- 在强制颜色模式下，文本和字形使用系统的文本颜色，禁用项中使用系统的禁用颜色。
- 调试构建会报告没有标题的行、既不是 1 也不是 2 的 `supportingLines`、被前置插槽取代的前置字形，以及未知的密度。

### 需要你做的事

- 为行提供 `headline`。
- 用行的标题为静态行中的控件命名：开关叫"蓝牙"，按钮叫"删除 brief.pdf"。
- 为前置插槽中的头像或图片提供替代文本，或者在标题已经说出这个人时将其隐藏。
