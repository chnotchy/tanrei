标签（Tag）是一个词或一个短语，说明某样东西是什么，或处于什么状态：文章的类别、构建的结果、版本所处的阶段、几个值当中的默认值。它位于布局之中，与旁边的文本同处一行，从不响应指针、按键或焦点。

在 Web 上它是 `<tanrei-tag>`。其他平台尚未实现。

## 指南

### 徽标、纸片还是 Tag

这三者只需区分一次，依据是它们各自做什么：

| 组件 | 它是什么 | 位于哪里 | 是否接受输入 |
| --- | --- | --- | --- |
| [徽标](/zh-cn/components/badge/) | 附着在另一个元素上的圆点或计数。 | 在锚点的角上，布局之外。 | 否。输入会落到锚点上。 |
| [纸片（Chip）](/zh-cn/components/chip/) | 一个控件。 | 在布局之中。 | 是：它可以被按下、切换或移除，并且有焦点和状态。 |
| Tag | 一段静态的文字标签。 | 在布局之中，与文本同行。 | 从不。 |

1. 如果它可以被按下、选中或移除，它就是纸片。如果它通向某个地方，它就是链接。
2. 如果它是叠在别的东西上面的一个数字或圆点，它就是徽标。
3. 如果它只是一个词，说明某样东西是什么或处于什么状态，它就是 Tag。

Tag 绝不会因为加了处理函数而变成控件。在链接、按钮、列表项或整体可按下的行里，它始终是那个元素的文本：落在它上面的输入会到达那个元素，悬停、聚焦和按下也由那个元素自己绘制。

### 如何选择外观

| `variant` | 绘制什么 | 用于 |
| --- | --- | --- |
| `tonal`（默认） | 柔和的填充。 | 大多数 Tag。 |
| `outlined` | 没有填充，只有一道细线。 | 许多 Tag 挨在一起的地方：表格的一列、一串类别。 |
| `filled` | 实色填充。 | 相邻几个当中被选定的那一个：几个值当中的默认值、几个字段当中的必填项。也用于那个绝不能被漏看的语义状态。 |

### 语义状态

`status` 为 `default`、`info`、`warning`、`error` 或 `success`。它只改变颜色。outlined 的 Tag 在每种语义状态下都保留表面的文本颜色和它的细线，所以它总会以该状态的颜色画一个圆点（或你提供的图标）：这个标记是该状态唯一显现的地方。

Tag 自己不绘制任何表示状态的图标。在有帮助的地方请自己指定一个，就像本站为自己的状态表中的六种状态所做的那样：

  <tanrei-tag size="small" variant="outlined" status="warning" label="待跟进"><span slot="icon">schedule</span></tanrei-tag>
  <tanrei-tag size="small" label="Alpha"><span slot="icon">clock_loader_40</span></tanrei-tag>
  <tanrei-tag size="small" label="Beta"><span slot="icon">clock_loader_80</span></tanrei-tag>

</Example>

### 尺寸

| `size` | 高度 | 文本 | 用于 |
| --- | --- | --- | --- |
| `small` | 20 | 12 | 字段的标签旁边、表格单元格里、一行正文之中。它不会把这一行撑高。 |
| `medium`（默认） | 24 | 14 | 标题旁边，或单独使用。 |

[字段](/zh-cn/components/field/)和[字段组](/zh-cn/components/field-group/)的“必填”和“选填”小标签，就是小号的这个组件：必填用 filled，选填用 tonal。它们读取 Tag 的令牌，没有自己的令牌，所以重新设定小号 Tag 样式的设计系统，也就同时重新设定了它们的样式。

### 位于禁用元素之中

Tag 没有自己的状态，但它可以位于一个被禁用的元素之中：禁用字段的标签、列表中禁用的一行、菜单中禁用的一项。`disabled` 用它所属外观的禁用颜色（`comp.tag.<variant>.disabled.*`）来绘制它，无论语义状态如何，让它随所在的元素一起变淡，而不是看起来像其中唯一可用的部分。除此之外它什么都不改变：Tag 保持自己的尺寸和文字，不接受输入，也不获得焦点。字段和字段组在禁用时会为它们的必填和选填小标签设置它；你把 Tag 放进自己的禁用元素时，请自己设置。

  <tanrei-tag size="small" variant="filled" label="必填"></tanrei-tag>
  <tanrei-tag size="small" variant="filled" label="必填" disabled></tanrei-tag>
  <tanrei-tag size="small" label="选填"></tanrei-tag>
  <tanrei-tag size="small" label="选填" disabled></tanrei-tag>
</Example>

### 推荐

- 用文字说出状态。“失败”无需更多说明；以错误颜色显示“3 个构建”的 Tag 则需要 `statusLabel`。
- 给 Tag 留出放得下标签文字的空间。放不下的文字会以省略号截断，而 Tag 没有悬停或聚焦可以用来显示其余部分。
- 一组 Tag 属于同一个集合时，例如一篇文章的类别，请把它们放进列表（在 Web 上是 `<ul>` 和 `<li>`），并为列表命名。

### 避免

- 不要让 Tag 可以被按下。可以被按下、切换或移除的标签是纸片；通向某个地方的是链接。
- 不要使用没有标签文字的 Tag。单独一个圆点或图标不是 Tag，它什么也不会绘制。
- 不要指望靠颜色来传达状态。在强制颜色模式下，每个 Tag 看起来都一样：一道边线，加上文本颜色的标签文字。
- 不要用 Tag 表示图标上的计数。那是徽标。

## 无障碍

<ComponentAccessibility name="tag" />

### 组件负责的部分

- 它没有角色，也没有名称：它的标签文字在 Tag 所在的位置作为文本朗读。在链接、按钮或表格单元格里，它是那个元素内容的一部分。
- `statusLabel` 作为另一个短语在标签文字之前朗读（“错误，3 个构建”），从不绘制。`status` 为 `default` 时它会被忽略。
- 图标和圆点对辅助技术隐藏。
- 它不接受输入，也不获得焦点，所以不会给焦点顺序增加停靠点，也不会给一行增加目标。
- 被截断的标签文字仍然会完整朗读。
- 在强制颜色模式下，每种外观都会多出一道文本颜色的边线，标签文字、图标和圆点也都采用这个颜色；禁用的 Tag 则采用禁用文本的颜色。
- `disabled` 不暴露任何东西：说明自己被禁用的，是 Tag 所在的那个元素。
- 在从右到左的布局中，图标或圆点移到标签文字的右侧，图标集标记为需要镜像的图标会被镜像，从左到右书写的标签文字保持自己的顺序，并在它自己的末尾截断。
- 未知的变体、尺寸或语义状态，空的标签文字，以及没有语义状态却设置了的 `statusLabel`，会在调试构建中报告。

### 需要你做的事

- 检查每个 Tag 的文字是否说出了它的状态。组件无法判断“3 个构建”是好消息还是坏消息。
- 用页面的语言来写 `statusLabel`。
- 只在位于禁用元素之中的 Tag 上设置 `disabled`，并确保那个元素说明了这一点（一个禁用的控件，或 `aria-disabled`）：变淡的 Tag 依赖于它。
- 如果某个变化必须在发生时就朗读出来（例如用户正看着的构建完成了），请把 Tag 放进实时区域（live region），或者用消息条（Snackbar）来报告这个变化。Tag 自己不会朗读。
