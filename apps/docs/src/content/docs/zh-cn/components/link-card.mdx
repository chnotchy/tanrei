链接卡片把目的地当作一样独立的东西来展示：它的标题、一句介绍、有图片时的图片，以及它所在的网站。它是一个链接。按下的是整个区块，里面没有任何东西可以单独按下。

- 句子里通向某个地方的短语，是[链接](/zh-cn/components/link/)。
- 把你自己的内容归为一组、并通向某个地方的，是带目的地的[卡片](/zh-cn/components/card/)。
- 带有自己的按钮（保存、分享、关闭）的预览，是一张容纳了链接和这些按钮的卡片。

**这个组件不获取任何东西。** 它只绘制你给它的值，从不就 `href` 向目的地、代理或任何服务询问任何信息。它发出的请求，只有你交给它的图片和网站图标。网站怎样得到这些值，见[取得这些值](#取得这些值)。

在 Web 上，它是包在你自己的锚元素外面的 `<tanrei-link-card>`。这个元素没有 shadow root，所以在任何脚本运行之前，卡片就已经是一个链接。其他平台尚未实现。

这段标记不需要手写。`@tanrei/web/links` 的 `linkCardToHtml()` 和 `linkCardToNodes()` 会根据这些值把它写出来，所以卡片在首次绘制时就是完整的，关闭脚本时也一样。

### 由脚本构建的卡片

里面没有锚元素的 `<tanrei-link-card>`，会根据自己的属性构建一个。每个值都作为文本写入，绝不作为标记。

```html
<tanrei-link-card
  href="https://example.com/articles/designing-with-tokens"
  headline="用令牌做设计"
  description="几个调节量如何变成一整套系统。"
  site-name="Example Journal"
></tanrei-link-card>
```

标题的属性是 `headline`，因为 HTML 自己的 `title` 会在卡片上方显示工具提示。这种形式要等脚本运行之后才会绘制。在内容页面上，请在构建时写出标记。

## 指南

### 你给它什么

| 值 | 属性 | 绘制成 |
| --- | --- | --- |
| `href` | `href` | 目的地。文本下方的主机名从它读出，不从别处读出。 |
| `title` | `headline` | 标题，最多两行。它是卡片的无障碍名称。 |
| `description` | `description` | 一两句话，最多两行。 |
| `image`、`imageAlt` | `image`、`image-alt` | 铺满图片框的图片，以中心为准裁剪。`imageAlt` 只朗读，从不绘制。 |
| `siteName` | `site-name` | 网站对自己的称呼，位于主机名之前。 |
| `siteIcon` | `site-icon` | 网站的小图标，位于网站行的起始处。 |
| `target`、`targetLabel` | `target`、`target-label` | `new` 在新标签页中打开，并绘制对应的标记。文字要由你给出。 |
| `external`、`externalLabel` | `external`、`external-label` | `auto`（默认）、`on` 或 `off`，与链接相同。 |
| `variant` | `variant` | `outlined`（默认）或 `filled`。 |

### 它通向哪里

卡片里的其他一切，都是目的地对自己的说法，而目的地可以说任何话。所以有一个部件不由目的地来说。

- 主机名由 `href` 计算得出。没有任何值可以设置它、替换它或隐藏它。标记里写的主机名如果与之不同，会在元素定义时被替换，调试构建会报告这一点。
- 网站的名称位于主机名之前，绝不取代它。名称只是重复主机名时，会被省略。
- 主机名绝不会被截断。行太短时，先让步的是网站的名称；主机名比这一行还长时，它会换行。
- 国际化的主机名只有在安全时才以它自己的文字显示：主机名里每个这样的段都只用一种文字，或者只用日语、韩语或汉语书写时会一起使用的那几种文字。混入一个外来字母的拉丁文名称，以及 ASCII 后缀之前的西里尔文或希腊文单词，都保持 `xn--` 形式。
- 主机名会作为卡片描述的一部分，朗读给辅助技术。

卡片不评判它的目的地。页面仍然可能对自己作虚假的描述；描述旁边的主机名，是读者用来核对的依据。同一种文字之内形似的字母，无法识别出来。

### 布局

- 卡片是一个区块。它的宽度由容器给定，高度取决于它容纳的内容。它不在自己周围带任何间距。
- 宽度达到 480 时，图片位于文本旁边，靠末尾侧的边缘。更窄时，图片位于文本上方。卡片依据的是自己的宽度，而不是窗口的宽度，这条界线会随文本大小而增大。
- 这个元素是一个尺寸容器，所以它需要由布局给定宽度。在 flex 行或网格单元格里，请给它一个宽度。
- 在长文里，它是一个像插图那样的区块。它绝不放在句子里面。

### 新标签页，以及其他网站

- `target="new"` 在网站行的末尾绘制 `open_in_new`。请给出 `target-label`（“在新标签页中打开”）；单靠标记是不会被朗读的。
- 目的地在其他网站、并且在用户当前所在的标签页中打开时，绘制 `arrow_outward`。它是不是外部链接，按链接的规则判定：`external="auto"` 把地址与页面的源以及 `setSiteOrigins()` 作比较。文字是 `external-label`，或者你用 `setExternalLabel()` 设置一次的那段文字。
- 绝不出现两个标记。新标签页优先。

Tanrei 不自带任何文字。请用你的产品的语言给出它们。

### 取得这些值

卡片绘制交给它的东西。请在**构建网站的地方**读取目的地，而不是在页面被阅读的时候。

`@tanrei/web/links/node` 是为此提供的 Node 模块。`resolveLinkData()` 在构建网站的机器上把一个页面读取一次，并按卡片接受的形状返回这些值。

```js
import { linkCardToHtml, resolveLinkData } from '@tanrei/web/links/node';

const result = await resolveLinkData(href, { site: ['docs.example.com'], lock: 'link-data.lock.json', pictureDirectory: 'public/link-pictures' });
const html = result.ok ? linkCardToHtml(result.data) : `<a href="${href}">${href}</a>`;
```

- 读到的内容保存在 `link-data.lock.json` 里，这个文件要提交到仓库。构建时读取的是这个文件，从不访问网络。`tanrei-links update` 会刷新它，而这次变更是一份由人来审阅的差异。
- 图片先由你自己的图像处理步骤重新编码，再保存到你的网站自己的文件当中。这样，读者的浏览器只会向它已经所在的网站发出请求。
- 这个辅助函数只读取公开的 `https` 地址，检查每一次重定向，限制时间和大小，并把每个字段都当作文本。
- 读取失败的地址不会得到卡片。请绘制一个普通的链接。

完整的说明见这个包的 README 中“Reading a destination where the site is built”一节。

如果你的产品要在用户使用的过程中查询目的地（例如一条带有地址的消息），请在你自己的服务里做这件事，并把同样的值提供给卡片。这样的服务必须拒绝任何不是公开地址的地址，在每一次重定向之后以及建立连接的那一刻再次检查，限制每个响应的时间和大小，只返回文本而绝不返回标记，从你自己的源提供图片，并且绝不返回主机名：主机名由卡片计算。Tanrei 不提供这样的服务。

### 推荐

- 给出目的地真实的标题。绝不要把主机名或地址放进标题。
- 把图片保存在你自己的文件当中。从其他网站加载的图片，会让那个网站知道是谁在阅读。
- 在连续文本里使用 `outlined`。页面上已经有很多线条的地方，使用 `filled`。

### 避免

- 不要在链接卡片里放按钮或第二个链接。它会被设为惰性（inert），并被报告。
- 不要把读者必须读到的文字放进链接卡片。它的文字是预览，可能被截断。
- 除非图片说了标题没有说的内容，否则不要给出 `image-alt`。

## 无障碍

### 组件负责的部分

- 卡片是一个链接，也是键盘的一个停靠点。Enter 前往它的目的地。Space 滚动页面，与任何链接一样。
- 它的名称是标题；没有标题时是地址。名称里不会添加任何内容。
- 它的描述依次是：描述、图片的替代文本、网站的名称、主机名，最后是说明新标签页或其他网站的文字。
- 在屏幕上被截断的标题或描述，会完整地暴露出来。
- 图片、网站图标、圆点和标记都是装饰，不会被朗读。
- 焦点环画在卡片外面，所以图片挡不住它。
- 文本放大到 200%、所在位置宽度为 320 时，图片移到文本上方，主机名保持完整，不会出现横向滚动。
- 在强制颜色模式下，两种外观都有一道边线，标题采用系统的链接颜色。
- 在从右到左的布局中，图片位于左侧，文本从右侧开始。从左到右书写的标题保持自己的顺序。主机名始终从左到右。
- 你给出的文本按纯文本绘制。会颠倒文本顺序的字符会被丢弃。

### 需要你做的事

- 只要 `target` 是 `new`，就给出 `target-label`；并给出外部链接的文字。
- 给出标题。地址是一个很差的名称。
- 让卡片从它的布局中得到宽度。
