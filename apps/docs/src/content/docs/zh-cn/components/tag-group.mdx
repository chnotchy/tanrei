一个[标签（Tag）](/zh-cn/components/tag/)、一个[纸片（Chip）](/zh-cn/components/chip/)，各自都只是一样东西。标签组用来容纳好几个这样的东西：一篇文章的标签、列表上方的筛选条件、字段下方的几条建议。它把它们排成会换行的若干行，让它们之间保持合适的距离，并告诉辅助技术它们是一个列表。

标签组自己什么也不绘制。它没有容器，没有边线，没有内边距，也没有可见的标签。每个成员的绘制、聚焦和按下，都与它在别处时完全一样。

在 Web 上它是 `<tanrei-tag-group>`。其他平台尚未实现。

## 指南

### 标签组用来做什么

| 这一组是什么 | 使用 |
| --- | --- |
| 静态的 Tag：文章的类别、一项设置可以取的值、一行状态 | 设置了 `spacing="tags"` 的标签组。 |
| 通往每个标签对应页面的标签 | 由带 `href` 的纸片组成的标签组。Tag 是文本，不能成为链接。 |
| 列表上方的筛选条件、字段下方的建议、用户输入的项 | 由纸片组成的标签组。 |
| 作为一个控件工作的筛选条件：一次只打开一个，或者打开好几个，只按一次 Tab 就能越过 | 设置了 `selection`、由筛选纸片组成的标签组（见下文）。 |
| 必须留在一行上的一排切换按钮 | [工具栏](/zh-cn/components/toolbar/)。 |
| 两到四个不同的操作 | [按钮组](/zh-cn/components/button-group/)。 |
| 几个当中选一个 | [单选组](/zh-cn/components/radio-group/)、[标签页](/zh-cn/components/tabs/)或[分段按钮](/zh-cn/components/segmented-button/)。 |
| 需要可见标签、必填和选填标记和错误信息的控件 | [字段组](/zh-cn/components/field-group/)。 |
| 字段里面已输入的值 | 由字段自己处理。[组合框](/zh-cn/components/combobox/)会自己排布它的纸片。 |

### 间距

`spacing` 说明这一组里放的是什么，并决定两个距离：同一行上两个成员之间的距离，以及两行之间的距离。

- `chips`（默认）用于纸片。纸片在可见边缘之外也接收按下，范围最大到一个触摸目标。行与行之间离得足够远，让每个中号纸片都保有完整的触摸目标；两个纸片的区域会重叠的地方，它们在间隙的正中相接。
- `tags` 用于静态的 Tag。行与行之间的距离和一行上 Tag 之间的距离一样近，所以换了行的一组读起来仍是一整块。

默认值是稳妥的一侧。留在 `chips` 的一组 Tag 只是彼此离得稍远一些。设为 `tags` 的一组纸片仍然可以工作，但它的行距小于触摸目标的高度，调试构建会报告这一点。

小号纸片用于密集、并且这一组只占一行的地方。换行之后，它们的触摸目标还没有达到完整大小，就已经在两行之间相接了。在触摸屏上会换行的一组，请使用中号纸片。

设计系统可以为 `spacing` 添加取值。

### 布局

- 成员按你给出的顺序排列。标签组从不对它们排序，也从不把选中的纸片移到前面。
- 放不下的成员会整个移到下一行。不截断、不缩小、不隐藏，也不滚动，更没有“还有 3 个”。想少显示一些，就少给标签组几个成员，并把最后一个做成显示其余成员的操作纸片。
- 比标签组还宽的单个成员，宽度等于标签组的宽度，并用省略号截断它自己的标签。
- 这一组从起始边开始排列。要把它放在一行的末尾或中间，请用它周围的布局来摆放标签组。
- 给每个成员相同的尺寸。尺寸不同的成员会在所在的行上居中对齐。
- 没有成员的标签组什么也不绘制，也不占空间。没有标签的帖子不需要特殊处理。

### 组的标签

`label` 为辅助技术给这一组命名：“标签”“筛选条件”。它不会被绘制。这一组需要可见的名称时，请在它前面写上你自己的标题或文字，同时仍然提供 `label`。

### 选择

默认情况下，标签组不持有值。每个筛选纸片持有自己的 `selected`，每个纸片各自是一个 Tab 停靠点。

筛选条件作为一个控件工作时，请设置 `selection`。给每个筛选纸片一个 `value`，标签组就会说出哪些纸片是打开的。

- `selection="single"`：最多只有一个纸片打开，由 `value` 指明。打开一个纸片会把其余的关掉。把打开的那个纸片关掉之后，就没有纸片打开，`value` 为 `null`，因为每个纸片都是一个开关。
- `selection="multiple"`：可以打开任意多个，由 `values` 指明。

用户切换一个纸片时，标签组设置 `value` 或 `values`，并触发一次带有 `detail.value` 或 `detail.values` 的 `change`。纸片自己的 `change` 到标签组为止。你自己设置 `value` 或 `values` 时，纸片会随之切换，但不触发任何事件。

有选择时，这一组是一个 Tab 停靠点：上次获得焦点的纸片；没有的话，是第一个打开的纸片；再没有的话，是第一个纸片。方向键按它所指的方向在纸片之间移动，在从右到左的布局中也是如此；Home 和 End 移到第一个和最后一个纸片。这些按键不切换任何纸片，焦点也不会从最后一个纸片循环回第一个。Space 切换获得焦点的纸片。

选择只包含筛选纸片。这一组里的其他纸片，例如“添加”纸片或已输入的项，用同样的方向键到达，并照常工作。已输入的项仍然用 Backspace 或 Delete 移除，之后获得焦点的纸片成为这一组的 Tab 停靠点。

你拿掉一个筛选纸片时，标签组让 `value` 和 `values` 保持原样。如果这个筛选条件也应当消失，请自己修改它们。

必须始终恰好有一个答案、且无法清除的选择，应使用[分段按钮](/zh-cn/components/segmented-button/)或[单选组](/zh-cn/components/radio-group/)。

### 移除纸片

纸片请求被移除，由你来移除它。如果当时焦点在这个纸片上，或在它的移除操作上，标签组会把焦点放到它后面的那个纸片上；后面没有纸片时，放到前面的那个上。连续移除好几项的人，可以从原来的位置接着做下去。

除非你在某个纸片上设置 `destructiveRemove`，纸片的移除操作都是普通外观，标签组也不会改变它。只有当移除会丢失一步无法恢复的东西时（例如附件），才设置它；已应用的筛选条件或搜索词一步就能恢复。

有两件事仍然由你负责：

- 没有纸片可以接收焦点时，请把焦点移到这一组所属的控件上：用来添加项的字段，或者打开筛选条件的按钮。否则浏览器会把焦点丢掉。
- 标签组不朗读任何内容。移除必须被听到时，例如被移除的筛选条件离它所改变的列表很远，请用实时区域（live region）或[消息条（Snackbar）](/zh-cn/components/snackbar/)来报告。

### 推荐

- 一组静态 Tag 请设置 `spacing="tags"`。
- 给这一组一个 `label`，使用页面的语言。
- 一组里只放一种成员。已输入的项后面跟一个“添加”纸片是例外。

### 避免

- 不要把标签组用于对话框或表单的操作。请使用按钮组。
- 不要在里面放 Tag 和纸片以外的东西。其他内容会照样排布，并在调试构建中报告。
- 不要从标签组去改成员的样式。请改为在层里更改标签组的令牌。

## 无障碍

<ComponentAccessibility name="tag-group" />

### 组件负责的部分

- 这一组作为一个列表暴露出来，由 `label` 命名。每个成员是其中的一项：Tag 作为它的文本朗读；纸片作为它的按钮或链接朗读，并带上状态；输入纸片旁边还有它的移除操作。
- 列表会告诉用户一共有多少个成员，以及自己正在其中的哪一个：“列表，4 项”。
- 成员按给出的顺序朗读和获得焦点，在从右到左的布局中也是如此。
- 没有选择时，每个纸片在焦点顺序中各是一个停靠点，输入纸片也只是一个：Tab 会跳过它的移除操作，在纸片上按 Backspace 或 Delete 即可移除它。标签组不获得焦点，也不处理任何按键。
- 有选择时，这一组是一个停靠点。方向键、Home 和 End 在它的纸片之间移动，每个筛选纸片仍然说出自己是否处于按下状态。标签组仍然是一个列表，所以屏幕阅读器仍然会说出一共有多少个纸片。
- 获得焦点的纸片被移除之后，焦点会移到下一个纸片上，绝不会移到移除操作上。有选择时，那个纸片成为这一组的停靠点。
- 空的标签组不暴露任何东西：没有空列表，也没有名称。
- 文本放大到 200% 时，成员变大，并换到更多的行上。不截断任何内容，也不出现横向滚动。
- 在强制颜色模式下，标签组和平时一样什么也不绘制。成员绘制各自的边线。
- 在从右到左的布局中，每一行都从右侧开始。

它在 Web 上的构建方式：列表是标签组 shadow root 里的一个元素，包在插槽外面。成员在标签组里的时候，标签组会给每个成员写上 `role="listitem"`，成员离开时再把它拿掉。自己已有 `role` 的成员，或者本身就有含义的原生元素（链接、按钮），会保留原有的角色，不算作列表项。请把这样的元素包在 `span` 里。

Web 上的已知差距：

- 在元素定义之前，成员按顺序出现在页面上，彼此之间只隔着它们之间的空白，没有间距，也没有列表。想让页面从首次绘制起就有这个布局，请添加：

  ```css
  tanrei-tag-group:not(:defined) {
    display: flex;
    flex-wrap: wrap;
    align-items: center;
    gap: var(--tanrei-comp-tag-group-row-gap-chips) var(--tanrei-comp-tag-group-gap-chips);
  }
  ```

### 需要你做的事

- 给标签组一个 `label`。组件不自带任何文字。
- 给每个输入纸片一个说出其项目名称的 `removeLabel`。
- 有选择时，给每个筛选纸片一个在这一组中唯一的 `value`。没有 `value` 的筛选纸片不参与选择，调试构建会报告这一点。
- 纸片触发 `remove` 时移除它；最后一个也移除之后，自己移动焦点。
- 用每个 Tag 自己的文字说出状态。只靠颜色永远说不出状态。
