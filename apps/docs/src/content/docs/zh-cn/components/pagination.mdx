分页按页码为同一个列表翻页：搜索结果、一个博客的帖子、一个表格的行。在一系列有标题的页面（例如一份指南的各章）之间前后移动的是[上一页/下一页链接](/zh-cn/components/previous-next-links/)：标题说明它通向哪里，页码说明不了。

### 用法

给出当前页和总页数。要显示哪些页码，由分页自己算出。有 `href` 时，每一页都是指向它自己地址的链接。没有时，各页是按钮，页面变化时由你更换显示的内容。

<Tabs syncKey="platform">
  <TabItem label="Web">

    ```html
    <!-- 链接：每一页都有可以收藏、分享或在新标签页中打开的地址。{page} 会填入页码。 -->
    <tanrei-pagination label="搜索结果的页面" page="3" count="12" href="/results/?page={page}"
      previous-label="上一页" next-label="下一页" page-label="第 {page} 页"></tanrei-pagination>

    <!-- 按钮：页面在原地变化。元素先设置自己的 page，再触发 change；取消它，页面就保持不变。 -->
    <tanrei-pagination id="pages" label="页面" page="1" count="10"
      previous-label="上一页" next-label="下一页" page-label="第 {page} 页"></tanrei-pagination>

    <script type="module">
      import '@tanrei/web/components/pagination';
      document.querySelector('#pages').addEventListener('change', (e) => showPage(e.detail.page));
    </script>
    ```
  </TabItem>
  <TabItem label="React">

    ```tsx
    <Pagination label="页面" page={page} count={10}
    ```

SwiftUI、Compose、Flutter 和 React Native 尚在计划中：本页开头各平台旁边的名称是规格为它们定下的，这些平台目前还没有提供任何实现。

文字由你提供：Tanrei 自己不提供任何文字。可以在每个元素上分别给出，也可以用 `setWords()` 为整个产品一次性给出（`previousPageLabel`、`nextPageLabel`、`firstPageLabel`、`lastPageLabel`、`pageLabel`、`pageCountText`）。

## 规格

<Example label="简短形式，以及小尺寸" column>
  <tanrei-pagination label="紧凑演示的页面" variant="compact" page="3" count="10" previous-label="上一页" next-label="下一页" count-text="第 {page} 页，共 {count} 页"></tanrei-pagination>
  <tanrei-pagination label="小尺寸演示的页面" size="small" page="4" count="8" previous-label="上一页" next-label="下一页" page-label="第 {page} 页"></tanrei-pagination>

<Example label="在窄栏中，带页码的形式会变成简短形式">

    <tanrei-pagination label="窄栏演示的页面" page="5" count="10" previous-label="上一页" next-label="下一页" page-label="第 {page} 页" count-text="第 {page} 页，共 {count} 页"></tanrei-pagination>
  </div>

- **显示哪些页码。** 第一页和最后一页（`boundaries`，默认为 1），当前页以及它两侧各一页（`siblings`，默认为 1）。它们之间省去的页合为一个省略号。靠近两端时，另一侧会多显示几页，因此每一页上这一行的位置数都相同，宽度也保持不变。
- **当前页**以填充色绘制，并作为当前页公开。激活它不会发生任何事。
- **上一页和下一页**只有图标。在第一页和最后一页上它们被禁用，但保留各自的位置。加上 `first-last` 时，**第一页和最后一页**画在它们外侧。
- **简短形式**（`variant="compact"`）在上一页和下一页之间画出你的句子“第 3 页，共 10 页”。没有句子时，它画出用斜线连接的两个数字“3 / 10”，开发构建会报告缺少文字。带页码的形式在给定宽度放不下时，会自己变成简短形式。
- **两种尺寸**：`medium`（40）和 `small`（32），后者用于紧凑的地方，例如[表格](/zh-cn/components/table/)的状态行。
- **从右到左**时，这一行从右侧排起，箭头会镜像。数字用页面语言的数字书写。

## 指南

### 推荐

- 把它放在它所翻页的列表之后；列表很长时，列表之前也放一个。
- 每一页都有自己的地址时用链接（`href`），页面在原地变化时用按钮。
- 在[表格](/zh-cn/components/table/)下方，在状态行里使用 `small` 尺寸的简短形式；如果让用户选择每页行数，就在它旁边放一个用于此事的[下拉选择框](/zh-cn/components/select/)。当前显示的行的范围（“第 1–10 件，共 248 件”）是表格的状态文字。
- 页面变化时，在内容变化的地方说明变化了什么：一个标题，或者表格的状态文字。分页自己不朗读任何内容。

### 避免

- 不要用它在一系列有标题的页面之间前后移动。那是[上一页/下一页链接](/zh-cn/components/previous-next-links/)。
- 不要为只有一页的列表显示它。
- 不要在第一页和最后一页上隐藏上一页和下一页。它们被禁用并保留位置。

## 无障碍

<ComponentAccessibility name="pagination" />

### 组件负责的部分

- 一个导航地标包住一个列表。每一页和每个启用的控件都是一个链接或按钮，也是焦点顺序中的一站。
- 当前页以 `aria-current="page"` 公开，并以填充色绘制，而不只是换一种颜色。
- 禁用的控件不在焦点顺序中。箭头和省略号对辅助技术隐藏。
- 一页的名称包含人们看到的数字，所以说出所见内容来操作的人也能激活它。

### 需要你做的事

- 用 `label` 为这个地标命名，使用你的产品的语言。页面上还有别的导航，这个名称把它与它们区分开。
- 为各控件命名（`previous-label`、`next-label`，有 `first-last` 时再加上 `first-label` 和 `last-label`），并用 `page-label` 为各页命名。Tanrei 自己不提供任何文字。
- 更换列表时，说明变化了什么。分页会把焦点留在它的某一项上：被激活的控件；如果该控件已被禁用，则是新的当前页。
