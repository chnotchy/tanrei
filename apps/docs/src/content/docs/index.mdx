## Built to stay in sync

<CardGrid>
  <Card title="Two sources of truth" icon="description">
    Design tokens and component specs are the only hand-written contracts. Platform code, these docs and the status matrix are all derived from them, and CI fails when they drift apart.
  </Card>
  <Card title="Parity, not sameness" icon="extension">
    Every platform gets the same tokens, states and accessibility semantics, but keeps its own API shape: `enabled` in Compose, a null `onPressed` in Flutter, `.disabled(_:)` in SwiftUI.
  </Card>
  <Card title="A proven structure" icon="menu_book">
    Reference, system and component tokens; color roles; a typescale; tonal palettes generated per theme and contrast level. The look is restrained and near-monochrome.
  </Card>
  <Card title="Accessible by construction" icon="verified">
    Contrast pairs are checked for every theme and contrast level at build time. Visual size never decides the hit area, and the focus ring is part of every interactive spec.
  </Card>
</CardGrid>
