# packages/tokens-build — local rules

- Flow: `scheme.js` (theme → generated DTCG) → `reader.js` (the bundle's tokens, scheme by scheme) → `model.js` (the model of six schemes, and the token lint) → `invariants.js` → `ir.js` → `emit/*`. Emitters never read token files directly.
- **A bundle is read by `reader.js`, not by a general DTCG parser**, and what it reads is shared, never copied: a token's `$extensions`, its authored node and an unchanged value are the bundle's own objects; a normal form is made once per value; a token that comes out the same in two schemes is one object. Treat everything `tokens(scheme)` returns as read-only. The general parser (`loadResolverFromBundle`, `model.js`) is the oracle — `test/reader.test.js` holds the reader to it token by token and field by field, for every scheme of the default system — and the judge of value shapes (`lintValues`: its `core/valid-*` rules over the written values of the default scheme, each distinct value once per process). Do not put it back on the path of a build: it held 118 KB per token and took nine tenths of `generate`.
- **`test/budget.test.js` is a budget, not a benchmark**: heap held per token, a heap limit the resolution must fit under, time as a multiple of a fixed yardstick (`scripts/measure.mjs`). A failure is a finding — find what is kept twice or done twice; do not widen it to pass. The 150 MB ceiling is a decision for the owner when the vocabulary reaches it.
- The reader reads what Tanrei writes. A DTCG feature the bundles do not use (`$ref`, `$extends`, `$root`, a color as a string) is refused with a message, never read differently from the parser. To start using one, teach the reader and extend the comparison in `test/reader.test.js` in the same change.
- Every emitter must handle every token type in the model and throw on an unknown one. A new token category means touching `ir.js` and **all** emitters.
- Output must be deterministic (stable key order, fixed rounding): the drift check diffs it byte for byte.
- Never relax `invariants.js` to make a build pass. Thresholds: text 4.5:1 (7:1 in high contrast), non-text and focus 3:1. A status color is also held at 3:1 against its own tonal container, as the mark a tag or a snackbar draws there. In the default system the link color (as text) and the focus color (3:1) are also held on `secondary-container` and on each status's container, where a callout's body puts links and controls. What is read in a code block and in inline code is held against its own fill wherever a layer re-points it at a color no role pair holds.
- Every written path is recorded in `generated-manifest.json`; the edit-guard hook and the drift check rely on it.
- `resolve.js` is the pipeline in memory — `resolveSystem({ system | layerFile | layers, dir })` → chain, bundle, reader, model, warnings — and imports no emitter. `product.js`, the CLI, the MCP server and the Studio server stand on it; do not add another code path that writes a bundle to a temporary directory to read it back.
- Names come from `tanrei.config.json` (`CONFIG.namespace`). `@tanrei/token-engine` has no file access and takes the namespace as a parameter (`mergeLayers(layers, { namespace })`, `createPaletteEngine({ …, namespace })`, `legalOperations(descriptor, { namespace })`); pass it, do not write `'tanrei'`.
- The IR only grows while platform emitters read it: add fields, never rename or remove. A paint may be `{ kind: 'scheme', by }` (a `tone` / `contrast-pick` rule whose result differs between schemes); every emitter states all six values, each for its own scheme (`test/per-scheme-paints.test.js`, fixture `test/fixtures/tone-per-state.system.json`), and throws on a paint kind it does not know.
- An `extends` is an id before it is a path. It is written in a layer nobody has validated yet, so `layerChain` refuses anything that is not a system id (`SYSTEM_ID`, `pure.js`) before a reader sees it, and a product's own parent is found only through `localLayerFile(dir, id)` (`resolve.js`): a regular file inside `dir`, never a link that leaves it. Do not join an id into a path anywhere else.
- A font stack is interpreted once, in `fontStack()` (`ir.js`): `generic` is the CSS keyword as written, `genericClass` is one of the three classes every native platform has (`sans-serif`, `serif`, `monospace`). Emitters do not map generics on their own.
- Tests make temporary directories with `tempDir()` from `packages/tools/src/test-tmp.js` and call `leavesNothingBehind(after)`; `test/temp-dirs.test.js` fails on a direct `mkdtemp`.
- The resolver reads the `scheme` modifier last (`tokens/tanrei.resolver.json`): a scheme's documents hold what differs between schemes — the color roles, every state color, and a resting component color a layer values by a color rule (`mix`, `alpha`, `tone`, `contrast-pick`). Such a resting color is skipped by `resolveNumericTokens` and valued by `generateStateDocument` (`@tanrei/token-engine`), only in a component that declares states; a child layer's `$value` replaces the rule. Do not move the modifier back before the `sys` and `comp` sets.
