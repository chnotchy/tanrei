Code block: a syntax role a design system added to the axis is drawn from its two tokens on a page that loads
`@tanrei/web/code.css` too. The element used to insert that role's rule into the stylesheet it adopts — which a block
on such a page does not adopt, so the run was drawn plain — and an inserted rule has the browser build every rule of
the page again. Each run of an added role now carries its color and its weight in its own style
(`--_code-block-run-color`, `--_code-block-run-weight`), written by the element on the runs it writes and on the runs
the document gives, and taken off a run that names a role of the core again; one rule of `code.css` (and of the sheet
the element adopts without it) reads them. The core roles and plain code are drawn as before. Without script a run of
an added role is drawn plain, as before.
