Tag group: on a page that is still loading, the group reads where its members stand with the read phase's reads, before
any element writes. It read them in its own observer's first report, which a frame delivers after the observers made
before it. When one of those had written, the browser styled and laid out the whole loading page again for the group's
read. That happened now and then on a docs page, depending on how the frames fell. Once the page has been painted, the
group reads in its report as before.
