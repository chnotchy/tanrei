'@tanrei/web': patch
---

A `.tanrei-icon` or a `.tanrei-link` that a product slots into a Tanrei element drawn in a shadow root of its own (a button's label, a dialog's body) inside the product's own shadow root is now read there as in the document: a glyph that shows a direction is marked to mirror in right-to-left, and a standalone link takes its label's own direction, with the press feedback, `noopener` and the external mark. Before, only an element drawn in the light DOM (an accordion, an app shell, a table) had the shadow root it was in observed, so in a root that held only buttons and dialogs an `arrow_forward` kept pointing right in right-to-left, and a left-to-right link label read "!Next page" with its glyph at the wrong end. Every element of the package now tells when it is connected in a shadow root and when it leaves; one connected in the shadow root of another element of the package does not, since the package draws what is there itself. Nothing changes in the document, and nothing is read from styles or layout while the page loads. The bundle of an element drawn in a shadow root grows by about 90 bytes (gzip, at most 116); every bundle stays within its budget.
