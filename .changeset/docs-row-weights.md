Documentation site: the typography page says which weight a row is set at. A row that is a command or a place — a
menu item, an option, a search suggestion, a row of a navigation drawer or a table of contents — is set at the label
weight, 500; a row of content — a list's, a tree's, a table's — at the body weight, 400. It is the rule the default
system's tokens already follow (a search suggestion's headline takes a combobox option's label style); the sentence
is in all six languages. No token, component or snapshot changes.
